# ОСКОЛ · DEV 0.7 / итерация 05

Одиночный офлайн 3D-survival для Android, Windows x64 и браузера. Авторский прототип, вдохновлённый добычей/стройкой Rust; **не Rust, не продукт Facepunch**. Без мультиплеера, внешних API и рекламы. Старая аркада сохранена отдельно в `web/layer/` и предыдущих релизах.

## Пакеты и проверка

[GitHub Actions → DEV05, build only](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml):
- `Oskol-Android-dev05-NO-TESTS` — `oskol-0.7.0-dev05-android.apk`, SHA-256; Android 8+, WebGL 2, актуальный System WebView. Version code 7, прежние application ID и development-подпись.
- `Oskol-Windows-x64-dev05-NO-TESTS` — portable EXE, инструкция, SHA-256; Windows 10/11 x64. Прежний каталог сохранений `%APPDATA%/oskol-survival/Local Storage`.

Артефакты скачиваются с входом в GitHub. Репозиторий публичный; автоматической публикации Release/магазина нет. Windows-пакет не подписан коммерческим сертификатом: не отключайте защиту ради запуска прототипа.

**По просьбе пользователя тесты не запускаются.** В CI только esbuild, Gradle `assembleDebug` и упаковка Electron — без unit/browser/native smoke, эмулятора и lint. Исторические тестовые исходники оставлены, но их старые результаты не являются подтверждением DEV05. Успешная сборка не проверяет игру на реальном телефоне/ПК, баланс, коллизии, FPS или Alt+Tab.

## Новое в DEV05

### Все иконки и лут без размножения инструментов
- **88 / 88 предметов имеют собственную цветную прозрачную WebP-иконку 256×256**, используемую в поясе, рюкзаке, крафте, требованиях, печи, торговле и луте. Сохранены 20 ранее отдельно AI-сгенерированных иллюстраций; остальные 68 — индивидуальные авторские векторные иллюстрации, не общие белые пиктограммы и не 68 AI-генераций. Источники SVG, происхождение и SHA-256: `web/assets/items/`.
- ×2…×50 **не размножают топоры, кирки, киянки, оружие и отдельное снаряжение**: максимум одна штука каждого такого типа на случайную выдачу. На ящик по-прежнему максимум одна пушка суммарно.
- Патроны и ракеты ограничены **одним стаком каждого типа (64)**. Ресурсы/компоненты получают множитель, но не более одного ресурсного стака каждого типа (1000); еда/медикаменты/метательная взрывчатка — до 20. Крафт, магазин и переработка не получают повторного множителя.
- Уже созданные случайные контейнеры нормализуются при загрузке/открытии. **Свои ящики, шкафы, мешочки и уже взятый инвентарь не обрезаются.** При переносе в собственный ящик можно хранить несколько инструментов и стаков.
- Бочки стоят **вокруг** сгоревших машин/грузовиков/мусора с угловым разбросом, а не в одну линию. Для каждой бочки независимый детерминированный бросок: усовершенствованная **60%**, обычная **20%**, нефтяная **20%**. Это вероятности, а не требование ровно 6/2/2 в любой десятке.

### Дома, рельеф и оптимизация
- Генератор рассчитан на **1200 домов**, в десять раз больше DEV04, с **1–10 этажами**, внутренними лестницами, проёмами между этажами, несколькими дверями, шкафом и ящиками. Домовых ботов нет; четыре охранника опасных РТ сохранены.
- Один строительный материал на весь дом: **дерево 40%, камень 40%, железо 20%**. Нет прежнего чередования камня и металла по деталям одного дома. Вероятности следов рейда 25% и остаточного лута 50% сохранены.
- Дальние дома — три инстансированных набора силуэтов по материалам. Полная геометрия, коллизии и взаимодействия подгружаются только у ближайших домов: до 12/24/40 по качеству, постепенно, с выгрузкой удалённых. Повреждения, лут и состояние открытых дверей сохраняются при выгрузке. Это не 1200 одновременно детализированных домов.
- Геометрии/материалы домов переиспользуются, стены/перекрытия инстансированы. Добавлены пространственный индекс опорных поверхностей и кэш уничтоженных ID, чтобы движение не перебирало все этажи карты на каждом подшаге.
- Новый рельеф: гребни, несколько холмов/массивов и мелкие неровности поверх прежних гор и реки. Фундаменты подгоняются по углам, опоры доходят до земли, входные ступени учитывают высоту склона.
- **Максимальное сглаживание по умолчанию:** MSAA до 8 samples, но не выше фактически поддерживаемого форматом устройства, плюс SMAA. Ландшафт и руки проходят один сглаживаемый кадр. В настройках есть стандартный режим без постобработки для снижения нагрузки. Максимум сглаживания тяжелее для GPU; обещаний прироста FPS нет.

### Взаимодействия и разрушение
- На ПК перетащи свой слот и отпусти **вне окна инвентаря** — предмет выбрасывается. На Android удержи слот 0,28 с и перенеси; обычный вертикальный свайп до удержания продолжает прокрутку. Половина стака учитывается. Перенос внутри окна/в печь/ящик остаётся переносом, а не выбрасыванием.
- Подрывной заряд и взрывная сумка **приклеиваются к поверхности при столкновении**, сохраняют локальную точку/поворот на открывающейся двери, затем взрываются по запалу. При разрушении опоры отклеиваются и падают. Гранаты не клеятся, а отскакивают. Упрощённая физика, не полная баллистика.
- При сносе фундамента рушатся потерявшие опору стены, перекрытия, двери, шкаф и установленные предметы. Для своей постройки проверяется связность опор; у процедурного дома детали привязаны к несущему фундаменту. Каскад может затронуть все этажи.
- Содержимое своих ящиков/шкафов/печей и рухнувших случайных ящиков переносится **без множителя** в мешочки с ручным открытием как лут-контейнера. Печь отдаёт также входы, топливо и выходы. Мешочки отличаются от деревянных ящиков и сохраняются.

### Руки, звуки, поверхности
- Вместо набора отдельных шаров/капсул — непрерывные меши ладони/запястья/рукава и **скелетные пальцы**. Разные хваты камня, инструмента, факела, плана, длинного оружия, пистолета и заряда; поддерживающая рука и движение при перезарядке. Это собственные процедурные модели/позы, не AAA-скан рук и не mocap.
- Локальные PCM-эффекты: разные выстрелы пистолета/винтовки/ПП/дробовика/ракетницы, перезарядка, взрыв, обрушение, двери, шаги, приземление и падение предметов. Громкость посадки зависит от скорости, шаги различают поверхности. Падение с большой высоты теперь причиняет урон с отдельным объяснением.
- Деревянные ящики со створками/планками, железными обвязками и замком; шкафы с петлями/запором; авторские поверхности досок, каменной кладки, лоскутного металла с ржавчиной/заклёпками и ткани. Изучены визуальные референсы Rust, **чужие игровые текстуры/модели/записи звука не включены**. Звуки сгенерированы локально скриптом `scripts/make-sounds05.py`, а не записаны с реального оружия.

## Сохранённые механики

Пляжный новый старт только с камнем в слоте 1 и факелом в слоте 2; возрождение на пляже. Ctrl — приседание, Shift — бег только вперёд, без выносливости. 20 РТ, две торговые мирные зоны, 12 видов оружия, три ракеты, гранаты, переработка и ремонт, крафт 4×4 с категориями/количеством, круг плана, материалы солома→дерево→камень→металл, отдельные крафтовые deployables. Печь только внутри: 1 топливо / 2 одновременно плавящиеся руды / 3 выхода. Шкаф оплачивает материал отдельно; нехватка металла разрушает металлические части, а не весь дом. Офлайн-гниения нет. Дороги, биомы на карте, день/ночь, лодки/нефтеплатформы, свои отметки и рюкзак с ручными переносами сохранены.

Размеры 650 / 910 / 1170 / 4000 / 8000 м; множители ×1/2/5/10/50. Сохранение `oskol.survival.v2` не обнуляет свой инвентарь/постройки. При первом открытии старого мира создаётся дополнительная копия `.pre-dev05`; исходный вариант рельефа старого мира сохраняется, чтобы не поднимать землю под старым домом. Генерация чужих домов изменена. **Для нового рельефа нужен новый мир**, который заменяет прежний после подтверждения.

## Управление и сборка

WASD/стик — движение; мышь/свайп справа — обзор; Shift/кнопка — бег, Ctrl/CTRL — присед; Space/кнопка — прыжок; ЛКМ/F/удар — атака, E/действие — взаимодействие; I/Tab — рюкзак, C — крафт, B/ПКМ с планом — стройка, M — карта; R — перезарядка/поворот, Q/Z — высота фундамента; ПКМ с оружием — прицел; 1–6 — пояс. F11 — полный экран Windows. Android: Back — пауза/закрытие окна.

```sh
npm ci
npm run build
npm run dev             # 0.0.0.0:3000
npm run build:windows   # Windows host
cd android && gradle --no-daemon :app:assembleDebug  # SDK35, JDK17, Gradle8.13
```

Лимиты: один активный мир, 400 своих элементов, 500 мешочков, ограниченное число детальных домов одновременно; физика/ИИ/структурная связность упрощены. Не заявляется проверенная проходимость всех этажей, безошибочная мобильная раскладка или стабильный FPS: **runtime-тесты DEV05 не запускались по просьбе пользователя**. Лицензии прежних ассетов: `web/assets/licenses/`; оригинальные новые текстуры, модели, иконки и звуки снабжены исходниками.
