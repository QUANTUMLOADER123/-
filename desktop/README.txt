ОСКОЛ — DEV 0.6, итерация 04 · БЕЗ ПРОГОНА ТЕСТОВ
Windows 10/11 x64. Запустите портативный EXE. F11 — полный экран.
Офлайн. Сохранения: %APPDATA%/oskol-survival/Local Storage.
WASD — движение, Shift — бег только вперёд, Ctrl — присесть, Space — прыжок.
ЛКМ/F — удар/выстрел/бросок, E — действие/установка. ПКМ — прицел / круг плана.
I/Tab — рюкзак, C — крафт, B — строительный план, M — карта, 1—6 — пояс.
R — перезарядка по времени или поворот постройки; Q/Z — высота фундамента.
Новый старт — только камень и факел на пляже. Возрождение тоже на пляже.
Крафт: категории слева, 4×4 карточки в центре, требования и количество справа.
Плавка ТОЛЬКО в печи: дерево + 2 руды → 3 выходных слота; результат забирается вручную.
Шкаф принимает ресурсы и оплачивает соответствующие материалы дома; при отсутствии металла гниёт только металл.
120 домов со шкафами, без домовых ботов. 20 РТ, мирные зоны с магазинами, 4 охранника опасных РТ.
Бочки/ящики разного уровня, компоненты оружия, переработка, ремонт, ракетница/гранаты.
Старый инвентарь/свои постройки сохраняются; новый старт требует «Новый мир» и подтверждение замены.
Это оригинальный прототип, НЕ Rust и не продукт Facepunch. Модели/физика/ИИ упрощены.
Сборка не проходила игровые/браузерные/native-тесты DEV04. FPS и Alt+Tab на вашем ПК не измерялись.
EXE не подписан сертификатом Windows. Не отключайте защиту; при сомнениях собирайте из исходников.
