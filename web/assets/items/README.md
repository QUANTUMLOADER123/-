# Цветные предметные иконки ОСКОЛ

Готово: **20 / 49**. Остальные пока используют прежнее оформление.

Индивидуальная AI-генерация для проекта; не ассеты Facepunch. Прозрачный фон, lossless WebP 256×256, локальная загрузка без сети. Исходный магентовый фон удалён; RGB-фон не попадает в игру.

Обработка: `python scripts/process-item-art.py .artifacts/item-art/raw` (Pillow, только для подготовки). Упаковка и превью: `python scripts/package-item-art.py --part N --items id ...`. Сборка игры не требует Python. `manifest.json` содержит контрольные суммы. Исходные большие PNG не включены в приложение.

Единый стиль для следующих партий: отдельный предмет в трёхчетвертном ракурсе, реалистичная цветная игровая иллюстрация, мягкий студийный свет, читаемый силуэт, без текста/логотипов/рамки; чистый #ff00ff фон для удаления. Не лист вариантов.
