# ОСКОЛ · DEV 0.6 / итерация 04

Одиночный офлайн 3D-survival для Android, Windows x64 и браузера. Авторский прототип, вдохновлённый циклом добычи и стройки Rust; **не Rust, не продукт Facepunch и не финальная игра**. Чужих игровых ассетов Facepunch нет. Старая аркада «ЕЩЁ СЛОЙ» сохранена отдельно в `web/layer/` и прежних релизах.

- `Oskol-Windows-x64-dev04-NO-TESTS`: portable EXE, `START-HERE.txt`, SHA-256. Windows 10/11 x64; F11 — полный экран. Файлы не подписаны коммерческим сертификатом; не отключайте защиту Windows ради прототипа.

Для скачивания Actions artifacts нужен вход в GitHub. **По просьбе пользователя тесты НЕ запускаются:** ни unit, ни браузерные/native smoke, ни эмулятор, ни Android lint. В CI остались JavaScript build, `assembleDebug` и упаковка Electron. Успешная компиляция **не означает проверенную работоспособность игры или измеренный FPS на телефоне**. Репозиторий публичный; публикации в магазине, сервера, аналитики и автоматического Release нет.

## Новое в DEV04

### Персонаж и интерфейс
- Новый мир: **только камень в первом слоте и факел во втором**, никаких начальных ресурсов/еды/пушек. Возникновение и возрождение — только на сухой прибрежной полосе; поиск зависит от зерна и размера и не подменяется внутренней точкой острова. Вещи после смерти пока сохраняются, как в предыдущем прототипе.
- Ctrl — присесть; отдельная кнопка на Android. Выносливость и её шкала удалены из механики; старое поле сохраняется константой только ради совместимости файлов. Shift / бег на стике ускоряет движение **вперёд**, а не вбок/назад; диагональный ход остаётся обычным.
- Оригинальные низкополигональные кисти с сегментами пальцев и рукавами, поддержка оружия второй рукой. Переработаны силуэты оружия, магазины, прицелы, рукояти, ракетная труба. Это процедурные модели/позы, **не фотореалистичные руки и не mocap**.
- Крафт: категории вертикально слева, **ВСЕ** первой; в центре ровно **4×4 карточки** с переключением страниц; справа описание, требования, количество 1–100 / МАКС и кнопка изготовления. Отдельной вкладки «Плавка» больше нет. Боковая панель рюкзака показывает лут, печь, торговлю или обслуживание шкафа.
- Карта использует тот же `biomeAt`, что ландшафт: снег, пустыня, лес и побережье. Дороги, 20 РТ, дома, торговые зоны, свои отметки и положение персонажа нанесены поверх.

### Мир, добыча и экономика
- **20 РТ**, включая две нефтеплатформы и две мирные торговые зоны. Добавлены аванпост, посёлок торговцев, супермаркет, спутниковая станция, железнодорожное депо, шахтёрский посёлок, разбитая автоколонна и водонапорная башня.
- **120 домов вместо прежних шести**: 2×2 и 2×1, фундамент поднят по высшей точке углов, опоры доходят до грунта, к входам ведут ступени. У каждого дома есть шкаф и ящики. На стадии генерации шанс следов рейда — 25%; в таком доме отсутствуют двери и одна стена, ящики пустые либо с шансом 50% содержат уменьшенные остатки лута. **Домовых ботов нет**; четыре прежних охранника опасных РТ и волки сохранены.
- Придорожный лут сгруппирован у сгоревших машин, грузовиков и мусора: три металлические бочки в группе, а не одинокие россыпи. Синяя обычная — компоненты, красная продвинутая — лучшие детали и больше металла, тёмная нефтяная — немного топлива. Новые модели имеют цилиндрический корпус, рёбра, крышку и пробки.
- Четыре типа ящиков с **весами появления 50 / 25 / 15 / 10%**: обычный деревянный, красный инструментальный, военный и элитный. Эти проценты относятся к типам ящиков, не к четырём независимым броскам. Таблицы отличаются компонентами, инструментами, металлом, боеприпасами и силой взрывчатки.
- В найденном ящике **максимум одна пушка**, и множитель никогда не превращает её в несколько. Старый базовый шанс оружия 80% сохранён для обычного полноценного лут-ящика; остатки разграбленных домов имеют пониженный шанс. Содержимое создаётся один раз и сохраняется. Предметы забираются вручную; пустой случайный ящик исчезает, своё хранилище/шкаф — нет.
- Продажа компонентов и покупка предметов за металлолом у автоматов. В мирной зоне запрещены стрельба/удары и строительство, волки и охрана не атакуют. Разборочный верстак возвращает материалы без повторного множителя; ремонтный стол восстанавливает изношенный огнестрел за металл.
- Добавлены трубы, баллоны, корпуса оружия, листовой металл, лезвия, электроника, брезент, изолента, высококачественный металл и его руда, взрывчатка, продукты. **У всех оружейных рецептов обязательные компоненты.** На берегу есть собираемый плавник и камни; в глубине — конопля, ягоды, грибы, тыква, кукуруза и богатая руда. Волки дают мясо.

### Строительство, шкаф, печь
- **B / ПКМ с планом — круговое меню**: обычный и треугольный фундамент, стена, полустена, дверной проём, обычное и треугольное перекрытие, скатная крыша, лестница и пандус. Солома → дерево → камень → металл через киянку. Элементы плана не крафтятся заранее: ресурсы списываются при успешной установке.
- Дверь, костёр, печь, ящик, большой ящик, верстак, шкаф, переработчик и ремонтный стол — **отдельные крафтовые предметы**. Дверь требует проём. Q/Z и кнопки высоты поднимают фундамент; R поворачивает элемент. Скат привязывается к полустене и имеет наклонную опорную поверхность; лестницы/пандусы ведут к перекрытиям. Треугольники пока имеют сеточную, не Rust-эквивалентную геометрию/привязку.
- Шкаф принимает дерево, камень, фрагменты и высококачественный металл. Показывает стоимость в час и остаток времени для связанных частей дома. Солома/дерево оплачиваются деревом, каменные элементы — камнем, металлические — фрагментами. **Не хватает металла — гниют только металлические части**, а не весь дом. Расход ресурсов и гниение идут только во время активной игры, не офлайн/на паузе. Во вскрытом чужом шкафу можно авторизоваться для строительства поблизости; переделка чужих готовых стен пока не поддерживается.
- У печи **ровно шесть собственных слотов**: 1 топливо, 2 входа, 3 выхода. Две разные руды обрабатываются **одновременно** раз в четыре секунды; дерево горит восемь секунд, есть уголь. Поддерживаются металл, сера и богатая руда. Вставка топлива/руды автоматически запускает плавку; результат остаётся в печи и забирается вручную. Печь продолжает работать в своём открытом окне. Переполнение выходов останавливает цикл без потери входов. Из рюкзака нельзя мгновенно переплавить металл/серу/уголь.

### Оружие
- **12 видов огнестрела**: прежние семь плюс полуавтоматическая винтовка, тяжёлый пистолет, боевой дробовик, пулемёт и ракетница. Ёмкость, темп, урон и длительность перезарядки различаются.
- Перезарядка занимает время; патроны перекладываются только в конце. Руки/оружие наклоняются, магазин опускается. ПКМ с оружием — приближение/прицеливание; ПКМ с планом — круг строительства. На телефоне есть кнопка R.
- Обычная, скоростная и зажигательная ракеты летят отдельными снарядами и взрываются по столкновению. Разный радиус/урон, зажигательная оставляет кратковременную зону урона. Тип выбирается применением нужной ракеты в рюкзаке; R меняет заряженный тип с возвратом старого боеприпаса.
- Самодельная/осколочная гранаты, сумка и подрывной заряд используют бросок и запал вместо мгновенного разрушения по клику. Радиус взрыва опасен и для самого игрока. Это упрощённая физика/урон, не полноценная баллистика, осколки или симуляция разрушения.

У новых компонентов/оружия есть локально рендерящиеся 3D-миниатюры; часть старых предметов ещё использует SVG. Набор из всех 49 старых AI-картинок не объявляется завершённым.

## Управление

| Действие | ПК | Android |
|---|---|---|
| Движение / обзор | WASD / мышь | левый стик / свайп справа |
| Бег вперёд / присед | Shift / Ctrl | кнопки бега / CTRL |
| Прыжок | Space | кнопка прыжка |
| Удар / выстрел / бросок | ЛКМ или F | удар |
| Взаимодействие / установка | E | действие |
| Рюкзак / крафт / карта | I или Tab / C / M | экранные кнопки |
| План / выбор элемента | B, ПКМ с планом | кнопка выбора элемента |
| Перезарядка / поворот | R | R / ↻ |
| Прицеливание | ПКМ с огнестрелом | отдельного ADS пока нет |
| Пояс | 1–6 | касание слота |
| Пауза | Escape | экранная пауза / Back |

## Сборка из исходников без тестов

```sh
npm ci
npm run build
npm run dev
# Windows host:
npm run build:windows
# Android SDK 35, JDK 17, Gradle 8.13:
cd android && gradle --no-daemon :app:assembleDebug
```

Dev-сервер слушает `0.0.0.0:3000` и отдаёт локальные ассеты без внешних API. Файлы JS собираются esbuild, бинарники не коммитятся. Исходники исторических тестов оставлены, но **не запускаются в этой итерации/CI**.

Лимиты прототипа: 400 своих элементов, один активный мир, упрощённые модели/анимации/ИИ, отсутствие мультиплеера и полной инженерной системы. Работа Android, Windows, новый баланс, проходимость домов/скатов, коллизии и качество кадров **не проверялись runtime-тестами DEV04**. Лицензии ассетов: `web/assets/licenses/`; авторские дополнительные модели — `src/survival/*04.js`.
