# ОСКОЛ · DEV 0.18.0 / итерация 17

Одиночный офлайн 3D-survival для Android, Windows x64 и браузера. Авторский прототип, вдохновлённый добычей/стройкой Rust; **не Rust, не продукт Facepunch**. Без мультиплеера, внешних API и рекламы. Старая аркада сохранена отдельно в `web/layer/` и предыдущих релизах.

## Пакеты и проверка

[GitHub Actions → DEV17, build only](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml):
- `Oskol-Android-dev17-NO-TESTS` — `oskol-0.18.0-dev17-android.apk`, SHA-256; Android 8+, WebGL 2, актуальный System WebView. Version code 19, прежние application ID и development-подпись.
- `Oskol-Windows-x64-dev17-NO-TESTS` — portable EXE, инструкция, SHA-256; Windows 10/11 x64. Прежний каталог сохранений `%APPDATA%/oskol-survival/Local Storage`.

Артефакты скачиваются с входом в GitHub. Репозиторий публичный; автоматической публикации Release/магазина нет. Windows-пакет не подписан коммерческим сертификатом: не отключайте защиту ради запуска прототипа.

**По просьбе пользователя тесты не запускаются.** В CI только esbuild, Gradle `assembleDebug` и упаковка Electron — без unit/browser/native smoke, эмулятора и lint. Исторические тестовые исходники оставлены, но их старые результаты не являются подтверждением DEV17. Успешная сборка не проверяет игру на реальном телефоне/ПК, баланс, коллизии, FPS или Alt+Tab.

## DEV17 — новые РТ, резкий рельеф, бой и контакт

- **Все 20 РТ перестроены:** отдельные планы/силуэты, единые преобразования геометрии, коллизий, лестниц, лута и причалов; два мирных торговых РТ, две нефтеплатформы и прежние четыре охранника сохранены. Старые слои детализации больше не накладываются друг на друга.
- **Рельеф ревизии 8 — только новые миры:** узкие гребни, крутые уступы, скальные полки и отдельные валуны/выходы скал с ограничением возле дорог, реки, домов и РТ. Старый остров и земля под базой не перегенерируются.
- **Стрельба:** интервалы ×0.78, номинальный темп примерно +28%. Винтовки/АК/пулемёт — вверх-вправо; пистолеты/револьвер — вверх; ПП/дробовики/ракетница — вверх-влево. Прицел изменяется реально, а не только качается модель.
- **Контакт:** опора на краях машин согласована с радиусом игрока; конечные объёмы получили верхнюю опору; падение больше не принимает пересекающее положение без проверки. Добавлено ограниченное восстановление уже застрявшего игрока.
- **Звук после смерти:** возрождение закрывает паузу штатным путём и явно возобновляет AudioContext из нажатия пользователя, сохраняя настройки громкости.
- **Взрывчатка:** единые текстурированные модели заряда, сумки, гранат и компонента в руках, инвентаре и мире: ткань, ремни, пряжки, скосы, панель и декоративные детали. Не инструкция по настоящим устройствам.
- **Поверхности:** новые авторские 1024px PBR-наборы почвы/гравия, камня и древесины; обновлены дерево построек, предметов и лодки.
- **Камера:** убрана зависимость качания от ложной «движущейся» почти нулевой скорости. Для чёрных квадратов убраны несколько рисков рендеринга: нулевые матрицы, HDR/bloom и несовместимые MSAA-буферы. Причина вспышек на устройстве не подтверждена.
- **Логотип:** выбранный пользователем AI-арт, вырезанная надпись и новые Android/Windows-иконки; ночная галерея DEV15 сохранена.

Новые РТ, текстуры, бой и звук применяются и к продолжению сохранения. **Для нового резкого рельефа и скальных полей нужен новый мир.** Содержимое ящиков/постройки не обнуляются. Если старый персонаж оказался внутри заменённой геометрии РТ, предусмотрено локальное перемещение на свободную позицию.

Выполнены статический разбор, авторство ресурсов и компиляция; **нет игрового, визуального, звукового или тестового прогона**, нет измерений FPS и гарантии отсутствия всех застреваний/вспышек. [Технические решения DEV17](src/survival/DEV17.md).

## DEV16 — исправления ввода, предметов и дальности

- **Стрельба с зажатой ПКМ:** кнопки мыши обрабатываются независимо через mouse down/up, а не только первый PointerEvent. Отпускание ПКМ не снимает ЛКМ. Сенсорные кнопки атаки и всплытия отслеживают собственные пальцы.
- **Модели и хват:** заново авторски собраны все 14 моделей огнестрела/ракетницы, топор, кирка и молоток: силуэты со скосами, стволы с углублением, отдельные движущиеся механизмы. У АК изогнутый магазин. Оптика получает координаты крепления на планке; у пистолета планка движется со слайдом. Хват инструмента задан точками модели, топор/кирка держатся двумя руками. DEV14 остаётся единственным контроллером позы и IK.
- **Текстуры:** девять оригинальных PBR-наборов дерева, стали, полимера, ткани, резины, краски, ржавчины, латуни и органики применяются к новым моделям, компонентам и еде. Статичные детали объединяются по материалу, но не вместе с подвижными магазинами/затворами. Это авторская стилизованная геометрия, не сканы/AAA и не ресурсы Facepunch.
- **Предметы:** АК-47 (30 винтовочных патронов), компактный ПП-32 (32 пистолетных), антисептик (+45 HP), травматологический набор (+90 HP). Полные рецепты, компоненты, лут, боеприпасы, профили хвата/перезарядки, иконки и сохранение. Уже существовавшие шприц/аптечка получили модели и доступность в ящиках. Уведомление показывает реально прибавленное HP, а не +35 для любой еды/лекарства. Лечение остаётся мгновенным; жест — только визуальный.
- **Грибы:** ножка теперь под округлой шляпкой; исправлена сама геометрия, а не повёрнут весь предмет.
- **Рельеф ревизии 7:** широкие холмы, гряды и складки, сохранённые пляж/русло реки, меньшая зона выравнивания лагеря. **Только для нового мира.** Продолжение сохранения оставляет формулы старой ревизии и землю под базой. В меню указана фактическая ревизия острова.
- **Дальность:** отдельные режимы «Близко / Баланс / Далеко». На «Баланс» бюджет центров лесных групп ~235 м вместо прежних 850 м на высоком качестве. Базы-прокси разделены на пространственные группы 96 м вместо трёх мешей на весь остров. Детализация домов, дорожные объекты, пропы и дальние тени тоже ограничены. Фрустумное отсечение сохранено; радиус группы расширяет примерную границу. Отрисовка не определяет попадания/коллизии.
- **Машины:** оригинальные статичные седаны/пикапы с колёсными арками, наклонными стёклами, стойками, зеркалами, дисками, фарами, коррозией и открытым кузовом. Вдоль дорог ориентируются по направлению дороги; геометрия кешируется и объединяется по материалам. Это не управляемые авто и не новая симуляция подвески.
- Сохранены ночная галерея DEV15, слоты/постройки/обслуживание/множители и максимум одного огнестрела на случайный ящик. Старые крупные стопки шприцев/аптечек читаются без удаления; новые стопки — до 20. Каталог: **92 цветные иконки = 20 прежних AI + 72 авторские векторные**, не 92 AI-изображения.

**Границы:** выполнены авторство ресурсов, статический разбор, компиляция и упаковка. Игра, тесты, браузер, устройство и звук не запускались; нет замеров FPS или визуального подтверждения отсутствия клиппинга. Боты по-прежнему отдельная будущая итерация. [Технические решения и ограничения DEV16](src/survival/DEV16.md).

## DEV15 — почти чёрная ночь и плавная смена фона

- Перегенерирован **«Ночной дозор»**: два анонимных бойца в броне идут лицом к камере, почти чёрный лес и очень тёмное синее небо. По две зелёные точки ПНВ на шлем и два тонких зелёных лазера на автоматах; броня и лица почти скрыты. После AI-генерации окружающая экспозиция дополнительно приглушена без подавления зелёных источников. Это авторская иллюстрация, не игровой скриншот.
- Галерея из восьми локальных иллюстраций теперь есть **в главном блоке меню и на загрузочном экране**. Ночной сюжет всегда первый; остальные перемешиваются. Смена — после 12 секунд показа, с наложением нового изображения за 2.6 секунды и медленным небольшим панорамированием.
- Старый фон остаётся полностью непрозрачным, пока новый накладывается поверх него: убрано одновременное затухание обоих слоёв, которое могло давать провал в чёрный. Следующее изображение заранее декодируется; удерживаются только текущая/следующая декодированные иллюстрации. Кнопка следующего фона блокируется до завершения перехода. При ошибке остаётся прежний фон.
- Таймеры и движение выключаются при выходе из соответствующего экрана, фоновой вкладке и отмене входа. Позднее декодирование не меняет новый сеанс. `prefers-reduced-motion` отключает панорамирование и переходы. Текст, кнопки и индикатор загрузки не двигаются вместе с изображением.
- Руки DEV14, рельеф, сохранения, лут, физика, боты и игровой свет не менялись. Ради фонов создавать новый мир не требуется; меню по-прежнему не создаёт 3D-мир.

**Только авторство/обработка изображения, статический разбор, компиляция и упаковка APK/EXE.** Тесты и игровой/браузерный/native/визуальный/аудио-прогон не запускались. Просмотр исходной AI-иллюстрации при подготовке ассета не является проверкой её отображения в игре или плавности на устройстве. [Галерея и SHA-256](web/assets/ui11/README.md).

## DEV14 — кисти, хват и единый контроллер анимаций

**Работает и при продолжении старого сохранения. Создавать новый мир ради рук не нужно.** Ревизия острова остаётся 6, схема/ключ сохранения, application ID и development-подпись не меняются. Боты отложены, как было оговорено.

- **Новая авторская геометрия кистей:** плавные поверхности ладони и запястья, противопоставленный большой палец, три косточки на палец, плавные веса в суставах, ногти и перчатка без пальцев. Процедурные карты микрорельефа кожи/ткани/кожи перчатки создаются локально; сторонних моделей рук, mocap или материалов Facepunch нет.
- **Цельный деформируемый рукав** от плеча к манжете вместо двух раздельных капсул. Двухзвенный IK решается последним, после всех поз. Плечи в пространстве камеры, а не на качающемся оружии; запястья привязаны к кистям. Если поза выходит за длину руки, компенсируется скрытый плечевой якорь, а не растягиваются кости. Это художественное решение для вида от первого лица, не полнотелая биомеханическая симуляция.
- **Один владелец позы:** обновления рук DEV04/05/08 больше не выполняются, базовый bob рук отключён. Новый контроллер объединяет плавное появление предмета, шаг/остановку по фактической скорости, бег с опусканием на 30°, остаточное движение при повороте, приседание, прыжок/приземление и переход в плавание. Старое плавное движение камеры при Ctrl/mobile сохранено.
- **Отдельные хваты 12 единиц оружия**, включая двуручный пистолет, плюс камень, топор, кирка, киянка, факел, план и взрывчатка. Для рукояток инструментов точка хвата выводится из геометрии деревянной части, с ориентацией предмета. Указательный палец отдельно реагирует на выстрел/перезарядку. Неподдержанный предмет больше не подменяется камнем в руке.
- **ADS** рассчитывается по настоящему центру голографической рамки/прицела ракетницы с учётом преобразования оружия. FOV и отдача затухают плавно; бег, перезарядка, плавание и появление предмета имеют явный приоритет. HUD-крестик учитывает доступность и переход ADS. Лишний прежний цилиндрический прицел у bolt-винтовок скрывается только у held-модели.
- **Разные перезарядки:** извлечение/замена магазина (включая боевой дробовик); короб пулемёта; открытие барабана револьвера с патронами; отдельные патроны внутреннего магазина/дробовика с числом из реальной нехватки; открытие казённика, подача ракеты и закрытие. Левая кисть меняет ориентацию между цевьём, магазином и затвором. Правая работает с ручным затвором. Пистолетный затвор и помпа движутся после выстрела.
- Визуальная перезарядка берёт **тот же progress**, что и игровая. Установка магазина/ракеты привязана к `.52`, закрытие/досылание — к `.83`, как существующие звуковые сигналы. Боеприпасы по-прежнему выдаются только исходной логикой в конце; отмена сменой предмета и запрет старта на бегу сохранены. Поштучная подача — визуальное представление прежней атомарной перезарядки, не новая механика частичного заряжания.
- **Отдача на пружинах**, вспышка дульного среза и ограниченный пул из 8 визуальных гильз. У ручного затвора/помпы выброс отложен до их движения; револьвер не выбрасывает гильзы при каждом выстреле. Гильзы не являются добычей и не участвуют в коллизиях; время жизни ограничено 0.65 с.
- Отдельные события для удара, броска, установки/подбора/открытия двери. После броска пальцы раскрываются; использование последней гранаты не обрывает жест, следующий предмет появляется снизу. **Урон ближнего боя и запуск снаряда не отложены анимацией:** их прежние игровые моменты/кулдауны сохранены. Это не система melee hit windows и не новые баллистика/урон.
- Шейдеры новых рук/вспышек/гильз включены в отложенную подготовку входа. Пул гильз ограничен; старые снятые риги и новые skeleton/material/texture освобождаются при смене мира. Сохранён главный экран без создания 3D-мира.

**Только статическая работа с исходниками, компиляция и упаковка. Тесты, игровой/браузерный/native/визуальный/аудио-прогон не запускались.** Нельзя обещать идеальную анатомию, отсутствие пересечений на каждой фазе/пропорции экрана, точный визуальный контакт с миром или проверенный FPS. Это существенно новая авторская first-person анимация, не mocap/AAA-ассеты. Подробности и ограничения: [VIEWMODEL14](src/survival/VIEWMODEL14.md).

## DEV13 — низкие холмы, долины, берега и новая генерация

**Новая генерация включается только при создании нового мира (`contentRevision: 6`).** Продолжение сохранений ревизий 3–5 использует прежние формулы высот, берегов, рек, площадок РТ и размещения домов. Установка APK/EXE не должна сама пересоздавать остров. Новый мир заменяет прежнее сохранение после успешного входа; отмена входа DEV11 сохранена. В меню подписана ревизия сохранённого мира.

- Убраны из новой ветки высокие шумовые гребни и добавки 165/115 м на больших картах. Вместо них — низкочастотный континентальный рельеф, широкая асимметричная возвышенность, мягкие ложбины и плавное искажение координат. Плавный `tanh` ограничивает амплитуду без срезанных плоских вершин. Это художественная генерация, **не измеренная геология и не симуляция эрозии**.
- Горизонтальный размер острова больше не тянет вверх горы пропорционально масштабу. Усиление высот ограничено 1.65×; кодовый мягкий предел — `42 × relief` метров, не измеренная высота реальной вершины. Мелкие детали имеют фиксированные мировые длины волн 125/28 м и малую амплитуду: они не превращаются в огромные бугры на 8-км карте.
- На небольших новых картах общая сетка суши продлена под ближний шельф и обе нефтеплатформы. Опоры платформ доходят до нового дна. Для новых сохранений допустимая глубина игрока/мешочков расширена до −40 м, чтобы погружение на шельф не делало сохранение невалидным. Для старых ревизий пределы прежние. Урон от глубины не добавлен; кислород остаётся прежним.
- Не круглая кромка-купол: seeded берег с мысами/вогнутыми участками, пологая пляжная полоса, широкое постепенное повышение к суше и плавно уходящий под воду шельф. Низкие каменные выходы вместо прежних высоких декоративных прибрежных силуэтов. Сам ландшафт остаётся общей геометрией для физики и изображения.
- Единое извилистое русло с плавно убывающим уровнем к морю, берегами, широкой долиной и поймой. На новых картах река есть и на малых размерах. Ширина учитывает шаг общего треугольного рельефа, чтобы канал не был заведомо уже разрешения суши. Это авторское русло/приближённая пойма, не автоматически рассчитанная сеть водосбора или симуляция жидкости.
- Новые площадки РТ отодвигаются от русла до построения домов и расширенной дорожной сети. Влияние выравнивания защищает канал/берег. Переходы вокруг площадок расширены с прежних 9 м до минимум 28 м, чтобы уменьшить искусственные крутые стены. Лагерь имеет более широкий плавный переход. Дома дополнительно исключаются из узкой береговой полосы.

## DEV12 — поверхности, освещение, вода и дождь

- **6 новых авторских AI-поверхностей, 18 карт:** дерево, кладка, ржавеющий металл, бетон, лесная почва, асфальт. Цвет/микрорельеф — 1024², совмещённые AO/roughness/metalness — 512². Это художественно полученные материалы, не измеренные PBR-сканы. Нормали и шероховатость приблизительные; источники, SHA-256, каналы и ограничения: [pbr12/README](web/assets/pbr12/README.md).
- Дома, строительные уровни, ящики и РТ получают новые поверхности. Ржавчина локально уменьшает металлические блики. Дорожная текстура привязана к мировым метрам и не вытягивается по длине дорог; дорожная геометрия/проходимость не менялась.
- Ландшафт смешивает почву, скалу, песок и снег по уклону/высоте/существующему биому, с деталями нормалей и крупными цветовыми вариациями. На среднем/высоком качестве скальная diffuse-карта проецируется с трёх сторон. **Высоты/коллизии, расположение домов, seed/ревизия карты и сохранения не меняются.**

Локальная карта высот 80²/48 м отсеивает капли ниже земли/воды/дорожных настилов/крыш; кольца брызг возникают на этих поверхностях. Это приближённая растеризация, не трассировка: маленькие проёмы и сложные крыши могут давать артефакты. Под крышей не выключается весь дождь снаружи.
- Намокание постепенно затемняет и сглаживает материалы; после дождя поверхности сохнут медленнее. Накрытые поверхности в локальной зоне учитывают карту крыш. Новая погода не меняет добычу, здоровье, проходимость или физику.
- Море/река: Fresnel-блики, анимированные микроволны, прозрачное мелководье, глубинный цвет и пена побережья. **На высоком качестве** у моря добавлено реальное дополнительное отражение сцены относительно уровня моря; 512 px по ширине, периодическое обновление, только при подходящей высоте камеры и поддержке HDR. Это не SSR/RT и не отражения рек на разных высотах; волновая физика не добавлена.
- Деревья сохраняют готовые модели Quaternius; добавлены текстурная кора из уже атрибутированного Babylon-набора, UV стволов, вариация окраски, подсветка листвы на просвет и ветер с соответствующей деформацией теней. Трава получила градиент от основания к кончикам и общий с дождём ветер.
- Высокое + максимальное сглаживание + HDR: сдержанный bloom ярких источников. На «Балансе»/«Экономно» он выключен. Разрешение новых карт определяется при входе: 512 в экономном и 1024 в остальных режимах. Если переключить режим во время игры, для смены разрешения текстур нужно выйти и войти.

- Сохранены быстрый HTML-старт меню DEV11, подготовка/компиляция под экраном входа, отмена с сохранением прежнего мира. Карта цвета глубины воды тоже строится отменяемыми порциями. При выходе освобождаются отражения, дождевые ресурсы, дополнительные shadow-материалы, инстанс-буферы и карты теней; кеш пропов сбрасывается. Боты/оружие/лут/плавное приседание не перерабатывались.

**Без тестов, браузерного/игрового/визуального/GPU/native/аудио-прогона.** Только авторинг ассетов, статическое чтение, компиляция и упаковка. Компиляция JS не проверяет GLSL на реальном GPU. Качество изображения, ошибки укрытия от дождя, отражения, расход памяти, FPS и нагрев на устройствах не измерены; это итерация прототипа, не обещание AAA/фотореализма.

Внутри одной синхронной JS-операции или встроенного декодера мгновенная остановка не обещается. `Promise.allSettled` не позволяет позднему результату парсера попасть в уже уничтоженную сцену. При отмене нового мира прежнее сохранение не перезаписывается.

Первый фон — ночной дозор, остальные перемешаны; смена примерно каждые 10 секунд или кнопкой «Следующий фон». Это концепт-арт, не игровые скриншоты, что подписано на экране. Нет ресурсов Facepunch. [Список и SHA-256](web/assets/ui11/README.md).

## DEV08 — вода, столкновения, оружие и окружение

### Физика и управление
- `state.terrainHeight` теперь интерполирует **те же треугольники, что рисуются**; решётка не меняется при смене графики. Кэш вершин ограничен размером сетки и пересоздаётся по seed/масштабу/ревизии. Персонаж и трава больше не используют отдельную несовпадающую аналитическую поверхность.
- Мотор: подшаги до 1/120 с, контакт ног с рельефом, небольшие ступени, торможение/воздушное управление; отдельные режимы ходьбы/плавания. Разделены верх пола и потолок снизу — пловца не должно вытягивать наверх через мост. Коллизии машин составлены из повёрнутых корпусов/кабин, капот и крыша имеют опорные поверхности.
- Плавание с плавучестью, вертикальной скоростью, подъёмом и погружением: **Space — вверх, Ctrl — вниз**, направление взгляда управляет движением вперёд. На телефоне можно держать прыжок; присед используется для погружения. На берег выходят обычным движением.
- Повреждение от глубины/положения ног убрано. Воздух расходуется **только когда камера/голова под водой**, запас 28 секунд. После исчерпания — удушье 8 HP/с; на поверхности воздух восстанавливается. Новый источник урона и кислород валидируются/сохраняются. Под водой цвет/видимость меняются, на суше тумана нет.
- Дороги подразделены на короткие сегменты и имеют опорную поверхность. Через реку формируется поднятый мост с подъездами, настилом, стойками, перилами, опорами и коллизиями вместо асфальта по воде. Новая расстановка придорожных групп использует новые ID; прежний подобранный дорожный лут не мигрируется на новые группы.
- Tab повторным нажатием закрывает инвентарь; I тоже переключает его. Закрытие отменяет незавершённое перетаскивание. При загрузке сохранения внутри новой коллизии ищется ближайшая свободная точка, без сброса инвентаря/мира.

### Лут и оружие
- Бочки оставляют **мешочек с содержимым на земле**, без автоматической выдачи в карманы; содержимое и множитель сохраняются. Это не отдельная rigid-body симуляция каждого кусочка металлолома. Один мешок на источник, как для уничтоженных ящиков.
- Огнестрел, инструменты, расходники и размещаемые предметы автоматически идут сначала в свободные слоты пояса, затем в рюкзак. Материалы автоматически пакуются только в рюкзак. Существующие предметы пояса не вытесняются и не расходуются от самого подбора.
- Пули имеют скорость, гравитацию, сопротивление, время полёта, максимальную дальность и снижение урона. Вместо мгновенного попадания выполняется пересечение пройденного сегмента с рельефом/целями/укрытиями. Дробовики выпускают 8 дробин. Выстрелы четырёх RT-охранников тоже проходят эту систему; домовыми ботами мир не заселяется.
- Профили скорости/дальности: пистолеты 250–280 м/с / 180–200 м, ПП 290 / 230, дробь 180–190 / 85–90, винтовки 380–680 / 400–850. Это игровые параметры, не утверждение о достоверной судебной баллистике. Гравитация действует сразу, прицел пристрелян примерно на 50 м.
- Обычная ракета 55 м/с, HV 95, падение 4,4 м/с² и сопротивление. Ракета поворачивается по скорости; столкновения проверяются вдоль сегмента, включая повёрнутые коллизии мостов/машин.

### Взаимодействия и разрушение
- На ПК перетащи свой слот и отпусти **вне окна инвентаря** — предмет выбрасывается. На Android удержи слот 0,28 с и перенеси; обычный вертикальный свайп до удержания продолжает прокрутку. Половина стака учитывается. Перенос внутри окна/в печь/ящик остаётся переносом, а не выбрасыванием.
- Подрывной заряд и взрывная сумка **приклеиваются к поверхности при столкновении**, сохраняют локальную точку/поворот на открывающейся двери, затем взрываются по запалу. При разрушении опоры отклеиваются и падают. Гранаты не клеятся, а отскакивают. Упрощённая физика, не полная баллистика.
- При сносе фундамента рушатся потерявшие опору стены, перекрытия, двери, шкаф и установленные предметы. Для своей постройки проверяется связность опор; у процедурного дома детали привязаны к несущему фундаменту. Каскад может затронуть все этажи.
- Содержимое своих ящиков/шкафов/печей и рухнувших случайных ящиков переносится **без множителя** в мешочки с ручным открытием как лут-контейнера. Печь отдаёт также входы, топливо и выходы. Мешочки отличаются от деревянных ящиков и сохраняются.

Громкость посадки зависит от скорости, шаги различают поверхности. Падение с большой высоты теперь причиняет урон с отдельным объяснением.

## Управление и сборка

WASD/стик — движение; мышь/свайп справа — обзор; Shift/кнопка — бег, Ctrl/CTRL — присед; Space/кнопка — прыжок; ЛКМ/F/удар — атака, E/действие — взаимодействие; I/Tab — рюкзак, C — крафт, B/ПКМ с планом — стройка, M — карта; R — перезарядка/поворот, Q/Z — высота фундамента; ПКМ с оружием — прицел; 1–6 — пояс. F11 — полный экран Windows. Android: Back — пауза/закрытие окна.

```sh
npm ci
npm run build
npm run dev             # 0.0.0.0:3000
npm run build:windows   # Windows host
cd android && gradle --no-daemon :app:assembleDebug  # SDK35, JDK17, Gradle8.13
```

Лимиты: один активный мир, 400 своих элементов, 10 000 мешочков, ограниченное число детальных домов одновременно; физика/ИИ/структурная связность упрощены. Не заявляется проверенная проходимость всех этажей, безошибочная мобильная раскладка или стабильный FPS: **runtime-тесты DEV07 не запускались по просьбе пользователя**. Лицензии прежних ассетов: `web/assets/licenses/`; оригинальные новые текстуры, модели, иконки и звуки снабжены исходниками.
