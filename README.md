# ОСКОЛ · DEV 0.9 / итерация 07

Одиночный офлайн 3D-survival для Android, Windows x64 и браузера. Авторский прототип, вдохновлённый добычей/стройкой Rust; **не Rust, не продукт Facepunch**. Без мультиплеера, внешних API и рекламы. Старая аркада сохранена отдельно в `web/layer/` и предыдущих релизах.

## Пакеты и проверка

[GitHub Actions → DEV07, build only](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml):

- `Oskol-Windows-x64-dev07-NO-TESTS` — portable EXE, инструкция, SHA-256; Windows 10/11 x64. Прежний каталог сохранений `%APPDATA%/oskol-survival/Local Storage`.

Артефакты скачиваются с входом в GitHub. Репозиторий публичный; автоматической публикации Release/магазина нет. Windows-пакет не подписан коммерческим сертификатом: не отключайте защиту ради запуска прототипа.

**По просьбе пользователя тесты не запускаются.** В CI только esbuild, Gradle `assembleDebug` и упаковка Electron — без unit/browser/native smoke, эмулятора и lint. Исторические тестовые исходники оставлены, но их старые результаты не являются подтверждением DEV07. Успешная сборка не проверяет игру на реальном телефоне/ПК, баланс, коллизии, FPS или Alt+Tab.

## DEV07 — замена звука по просьбе пользователя

- Старый синтетический банк убран из приложения. **90 клипов на основе записей CC0, около 2,5 МБ**: пистолеты/револьвер, АК, ПП, СКС, болтовая винтовка, дробовик, механизмы перезарядки, шаги по траве/дереву/камню/снегу, удары по дереву/руде/металлу/бочкам, обрушение и посадка. Источники и авторы: `web/assets/audio/CREDITS.md`; полная лицензия CC0 в `web/assets/licenses/Audio-CC0-1.0.txt`.
- Выстрелы нарезаны из оригинальных записей с сохранением атаки/хвоста, а не созданы из генераторного шума. Варианты не повторяются два раза подряд. Классы вымышленного оружия делят ближайшую звуковую семью; ракетница использует обработанный записанный хлопок, не настоящую запись РПГ.
- Перезарядка звучит по фазам: извлечение → вставка → затвор; больше нет полной одинаковой перезарядки и в начале, и в конце. При смене оружия отложенные звуки перезарядки отменяются. Помповое ружьё получает отдельный взвод после выстрела.
- Удары по бочке отличаются от камня, добыча дерева — от руды. Шаги получают реальные варианты поверхности, присед тише, спринт громче/чаще, приземление зависит от скорости и не дублируется одновременным шагом.
- Выстрелы охранников и взрывы имеют затухание, стереоположение и потерю высоких частот с расстоянием. Собственное оружие остаётся разборчивым. Нет бесконечного электронного шипения ветра и пищащих подтверждений крафта/подбора.
- В настройках три сохранённых регулятора: общая громкость, выстрелы/эффекты, шаги. Компрессор ограничивает сумму пиков; одновременно не больше 24 голосов, вытесняемые голоса затухают, а не обрываются щелчком. Фоновая вкладка и пауза останавливают игровые эффекты.
- Все файлы включены в APK/EXE и работают офлайн. Предзагрузка/декодирование — один раз, максимум четыре параллельных задачи. Оригиналы 63 МБ остаются в игнорируемом рабочем кэше, а не раздувают приложение.
- **Тесты, игровой прогон и прослушивание на устройстве не проводились.** Выполнены офлайн-подготовка медиа и сборка. Это не утверждение о проверенной громкости/балансе на телефоне пользователя.

## Исправления DEV06 по замечаниям пользователя

1. **120 домов вместо 1200.** Сохраняются 1–10 этажей, несколько дверей и единый материал дома 40/40/20. Снижен лимит полной подгрузки: 8/16/28 домов для low/medium/high; дома с активными зарядами временно удерживаются дополнительно.
2. **Один разрушенный непустой ящик — один отдельный мешочек.** У мешочка есть источник, содержимое разных ящиков/печей/шкафов при обрушении не объединяется. Новые мешочки раздвигаются по свободным местам и опускаются на оставшиеся опорные поверхности. Старые уже объединённые мешочки нельзя восстановить по исходным ящикам — такого разделения в старом сохранении нет. Пустой ящик не создаёт пустой мешок. Обычное ручное выбрасывание всё ещё может пополнять мешок у ног.
3. Случайные ящики теперь ломаются инструментами, пулями и взрывами, а не только открываются. Содержимое выпадает целиком без повторного множителя, включая оружие. Собственные хранилища/печи продолжают отдавать свои сохранённые предметы.
4. **Оптимизация:** пространственный broad phase для ресурсов, интерактивных предметов и деталей дома при наведении; кэш уничтоженных ID при dormancy; O(n)-сопоставление мешочков с моделями вместо вложенного поиска; дальние мешочки скрываются после 120 м; тени обновляются до 15/10 Гц, а не на каждом кадре. MSAA + SMAA и ручной облегчённый режим оставлены. Измеренного прироста FPS нет — игровых прогонов не было.
5. Руки используют согласованные оси запястий без больших встречных yaw/roll-поворотов. Хваты привязаны к рукояти/цевью, предплечья подходят к кистям с соответствующих сторон. Инструменты больше не имеют постоянного бокового завала. Это исправление процедурных поз, а не сканы рук.
6. **Спринт:** оружие, инструмент, факел, план и заряд плавно опускаются на **30° вниз**. Пока идёт спринт или предмет ещё поднимается, нельзя стрелять, бить, метать заряд, использовать предмет или начинать перезарядку. Прицеливание отключается. Обычная ходьба не блокирует действия.
7. **Ракетницы в домах:** добавлены в пул военных ящиков. У каждого шестого по ID неразграбленного дома в одном верхнем ящике назначен тайник с ракетницей и ракетами. В остальных элитных/военных ящиках — случайный шанс. Максимум одна пушка на случайный ящик сохранён; уже обысканные ящики не перезаполняются задним числом.
8. **Интерфейс по приложенным Rust-референсам:** персонаж крупно слева, справа от него реальные показатели и снизу ряд экипировки; инвентарь 6×5 и пояс 6 по центру, быстрый крафт и добыча одновременно справа. Прозрачные серо-оливковые квадратные слоты, крупные иконки без мелких подписей поверх изображения, количество в углу; печь, торговля и обслуживание шкафа используют правую колонку. Отдельные предметы одежды/создание команды не симулируются: броня действует по прежнему правилу наличия в инвентаре, пустые места экипировки декоративны. Портрет существующего CC0-персонажа теперь 384×640 и в полный рост вместо 96×96. В портретном узком окне панели перестраиваются, в альбомном остаются три зоны.
9. **Прицел:** центральная точка, четыре контрастные тонкие риски с чёрным контуром, изменение зазора при движении/приседе, отдельный hit marker. В ADS остаётся точка; при спринте/поднятии оружия, стройке и открытом меню прицел скрыт. Трассер заканчивается в фактической точке попадания луча, а не в высоте земли под верхним этажом.
10. **Бочки на склонах:** наклон по нормали рельефа, высота по 12 точкам опорной окружности, обновлённые габариты коллайдера наклонённого цилиндра. Поднятые платформы не притягиваются к земле под ними. Пропорции бочек 60/20/20 сохранены.

Ниже — сохранённые механики и техническая основа предыдущей итерации с актуальными лимитами.

### Все иконки и лут без размножения инструментов
- **88 / 88 предметов имеют собственную цветную прозрачную WebP-иконку 256×256**, используемую в поясе, рюкзаке, крафте, требованиях, печи, торговле и луте. Сохранены 20 ранее отдельно AI-сгенерированных иллюстраций; остальные 68 — индивидуальные авторские векторные иллюстрации, не общие белые пиктограммы и не 68 AI-генераций. Источники SVG, происхождение и SHA-256: `web/assets/items/`.
- ×2…×50 **не размножают топоры, кирки, киянки, оружие и отдельное снаряжение**: максимум одна штука каждого такого типа на случайную выдачу. На ящик по-прежнему максимум одна пушка суммарно.
- Патроны и ракеты ограничены **одним стаком каждого типа (64)**. Ресурсы/компоненты получают множитель, но не более одного ресурсного стака каждого типа (1000); еда/медикаменты/метательная взрывчатка — до 20. Крафт, магазин и переработка не получают повторного множителя.
- Уже созданные случайные контейнеры нормализуются при загрузке/открытии. **Свои ящики, шкафы, мешочки и уже взятый инвентарь не обрезаются.** При переносе в собственный ящик можно хранить несколько инструментов и стаков.
- Бочки стоят **вокруг** сгоревших машин/грузовиков/мусора с угловым разбросом, а не в одну линию. Для каждой бочки независимый детерминированный бросок: усовершенствованная **60%**, обычная **20%**, нефтяная **20%**. Это вероятности, а не требование ровно 6/2/2 в любой десятке.

### Дома, рельеф и оптимизация
- Генератор рассчитан на **120 домов**, в десять раз меньше DEV05, с **1–10 этажами**, внутренними лестницами, проёмами между этажами, несколькими дверями, шкафом и ящиками. Домовых ботов нет; четыре охранника опасных РТ сохранены.
- Один строительный материал на весь дом: **дерево 40%, камень 40%, железо 20%**. Нет прежнего чередования камня и металла по деталям одного дома. Вероятности следов рейда 25% и остаточного лута 50% сохранены.
- Дальние дома — три инстансированных набора силуэтов по материалам. Полная геометрия, коллизии и взаимодействия подгружаются только у ближайших домов: до 8/16/28 по качеству, постепенно, с выгрузкой удалённых. Повреждения, лут и состояние открытых дверей сохраняются при выгрузке. Это не 120 одновременно детализированных домов.
- Геометрии/материалы домов переиспользуются, стены/перекрытия инстансированы. Добавлены пространственный индекс опорных поверхностей и кэш уничтоженных ID, чтобы движение не перебирало все этажи карты на каждом подшаге.
- Новый рельеф: гребни, несколько холмов/массивов и мелкие неровности поверх прежних гор и реки. Фундаменты подгоняются по углам, опоры доходят до земли, входные ступени учитывают высоту склона.
- **Максимальное сглаживание по умолчанию:** MSAA до 8 samples, но не выше фактически поддерживаемого форматом устройства, плюс SMAA. Ландшафт и руки проходят один сглаживаемый кадр. В настройках есть стандартный режим без постобработки для снижения нагрузки. Максимум сглаживания тяжелее для GPU; обещаний прироста FPS нет.

### Взаимодействия и разрушение
- На ПК перетащи свой слот и отпусти **вне окна инвентаря** — предмет выбрасывается. На Android удержи слот 0,28 с и перенеси; обычный вертикальный свайп до удержания продолжает прокрутку. Половина стака учитывается. Перенос внутри окна/в печь/ящик остаётся переносом, а не выбрасыванием.
- Подрывной заряд и взрывная сумка **приклеиваются к поверхности при столкновении**, сохраняют локальную точку/поворот на открывающейся двери, затем взрываются по запалу. При разрушении опоры отклеиваются и падают. Гранаты не клеятся, а отскакивают. Упрощённая физика, не полная баллистика.
- При сносе фундамента рушатся потерявшие опору стены, перекрытия, двери, шкаф и установленные предметы. Для своей постройки проверяется связность опор; у процедурного дома детали привязаны к несущему фундаменту. Каскад может затронуть все этажи.
- Содержимое своих ящиков/шкафов/печей и рухнувших случайных ящиков переносится **без множителя** в мешочки с ручным открытием как лут-контейнера. Печь отдаёт также входы, топливо и выходы. Мешочки отличаются от деревянных ящиков и сохраняются.

### Руки, звуки, поверхности
- Вместо набора отдельных шаров/капсул — непрерывные меши ладони/запястья/рукава и **скелетные пальцы**. Разные хваты камня, инструмента, факела, плана, длинного оружия, пистолета и заряда; поддерживающая рука и движение при перезарядке. Это собственные процедурные модели/позы, не AAA-скан рук и не mocap.
- С DEV07 локальные записанные PCM-эффекты: разные выстрелы пистолета/винтовки/ПП/дробовика/ракетницы, перезарядка, взрыв, обрушение, двери, шаги, приземление и падение предметов. Громкость посадки зависит от скорости, шаги различают поверхности. Падение с большой высоты теперь причиняет урон с отдельным объяснением.
- Деревянные ящики со створками/планками, железными обвязками и замком; шкафы с петлями/запором; авторские поверхности досок, каменной кладки, лоскутного металла с ржавчиной/заклёпками и ткани. Изучены визуальные референсы Rust, **чужие игровые текстуры/модели/записи звука не включены**. Синтетические звуки DEV05 заменены записями CC0; офлайн-обработка — `scripts/prepare-audio07.py`. Полное происхождение в `web/assets/audio/CREDITS.md`.

## Сохранённые механики

Пляжный новый старт только с камнем в слоте 1 и факелом в слоте 2; возрождение на пляже. Ctrl — приседание, Shift — бег только вперёд, без выносливости. 20 РТ, две торговые мирные зоны, 12 видов оружия, три ракеты, гранаты, переработка и ремонт, крафт 4×4 с категориями/количеством, круг плана, материалы солома→дерево→камень→металл, отдельные крафтовые deployables. Печь только внутри: 1 топливо / 2 одновременно плавящиеся руды / 3 выхода. Шкаф оплачивает материал отдельно; нехватка металла разрушает металлические части, а не весь дом. Офлайн-гниения нет. Дороги, биомы на карте, день/ночь, лодки/нефтеплатформы, свои отметки и рюкзак с ручными переносами сохранены.

Размеры 650 / 910 / 1170 / 4000 / 8000 м; множители ×1/2/5/10/50. Сохранение `oskol.survival.v2` не обнуляет свой инвентарь/постройки. При первом открытии мира до изменения плотности создаётся дополнительная копия `.pre-dev06`; исходный вариант рельефа старого мира сохраняется, чтобы не поднимать землю под старым домом. Генерация чужих домов сокращена до 120 и применяется к старому миру тоже. Свои постройки и содержимое контейнеров сохраняются; при первом переносе стоящий на крыше удалённого чужого дома игрок безопасно ставится на оставшуюся поверхность. **Для нового рельефа нужен новый мир**, который заменяет прежний после подтверждения.

## Управление и сборка

WASD/стик — движение; мышь/свайп справа — обзор; Shift/кнопка — бег, Ctrl/CTRL — присед; Space/кнопка — прыжок; ЛКМ/F/удар — атака, E/действие — взаимодействие; I/Tab — рюкзак, C — крафт, B/ПКМ с планом — стройка, M — карта; R — перезарядка/поворот, Q/Z — высота фундамента; ПКМ с оружием — прицел; 1–6 — пояс. F11 — полный экран Windows. Android: Back — пауза/закрытие окна.

```sh
npm ci
npm run build
npm run dev             # 0.0.0.0:3000
npm run build:windows   # Windows host
cd android && gradle --no-daemon :app:assembleDebug  # SDK35, JDK17, Gradle8.13
```

Лимиты: один активный мир, 400 своих элементов, 10 000 мешочков, ограниченное число детальных домов одновременно; физика/ИИ/структурная связность упрощены. Не заявляется проверенная проходимость всех этажей, безошибочная мобильная раскладка или стабильный FPS: **runtime-тесты DEV07 не запускались по просьбе пользователя**. Лицензии прежних ассетов: `web/assets/licenses/`; оригинальные новые текстуры, модели, иконки и звуки снабжены исходниками.
