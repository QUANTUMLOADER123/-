# ЕЩЁ СЛОЙ ↗

Офлайн-аркада для Android и браузера. Один палец, изометрическая башня и ещё одна попытка.

**[Скачать APK из GitHub Releases](https://github.com/QUANTUMLOADER123/-/releases)** · **[Сборки](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml)**

## Играть

- Нажми **ПОЕХАЛИ**, затем тапай по полю, когда края движущегося блока совпадут с башней. На компьютере также работает пробел.
- Направление меняется каждый этаж, скорость постепенно растёт. Лишняя часть блока отрезается.
- Три идеальных попадания подряд восстанавливают немного ширины. Пять дают одноразовую страховку; получить её повторно в той же попытке нельзя.
- Вызов дня: детерминированная последовательность и повышенная скорость, один набор условий на локальную календарную дату. Рекорд отдельный; сетевого рейтинга нет.
- Звук синтезируется на устройстве. Рекорды сохраняются локально; при очистке данных/удалении приложения они теряются.
- При сворачивании и блокировке игра встаёт на паузу. Кнопка «Назад» во время игры открывает паузу, с результата возвращает домой, с главного экрана закрывает приложение.

## Android APK

В каждом prerelease есть `one-more-layer-0.1.0-android.apk` и контрольная сумма SHA-256.

1. Открой Releases на телефоне и скачай APK из **Assets** последней сборки.
2. Разреши установку из выбранного браузера/файлового менеджера, если Android попросит.
3. Установи «ЕЩЁ СЛОЙ» и играй без сети.

**Это debug-подписанный прототип для ручной установки, не публикация в Google Play.** При несовпадении подписи между CI-сборками старую версию придётся удалить (с потерей её локальных рекордов). Для стабильных обновлений и магазина нужны постоянный закрытый ключ подписи, release-сборка/AAB, тестирование на устройствах и оформление страницы приложения. Не отключайте Play Protect. Минимальная ОС — Android 8.0; нужен обновлённый Android System WebView/Chrome с поддержкой современных JavaScript API (Chromium 94+).

Разрешение только на вибрацию. **Нет разрешения INTERNET**, рекламы, аналитики, аккаунтов, покупок, внешних шрифтов и сетевых ресурсов. Нативный контейнер отдаёт файлы из APK на внутреннем HTTPS-origin WebView, блокирует внешние переходы и предоставляет только вибрацию и системный обмен текстом.

## Локальный запуск

```sh
npm ci
npm run dev             # 0.0.0.0:3000, можно менять через PORT
npm test                # чистая логика, без браузера
npm run test:browser    # при уже запущенном dev-сервере
```

В браузерном тесте Chromium поставляется npm-пакетом. Тест сохраняет скриншоты в игнорируемую `.artifacts/screenshots/` и проверяет desktop, мобильные размеры 390×844 / 360×640 / 320×568, HiDPI-отрисовку, идеальное попадание, промах, повтор, сохранение рекорда, отдельный вызов дня, звук, правила и паузу. Все игровые файлы — в `web/`; production-зависимостей нет.

## Сборка Android

Нужны JDK 17, Gradle 8.13, Android SDK platform 35 и соответствующие build tools:

```sh
cd android
gradle :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

CI `.github/workflows/android.yml` запускается при push игровых/Android-файлов в `arena/ce299f3a-repo` или вручную. Он выполняет unit- и браузерные тесты, собирает APK, проверяет Android Lint, устанавливает приложение на Android 15/API 35 emulator и запускает smoke-тест настоящего WebView (загрузка локальных ES-модулей, полноэкранный HiDPI canvas, старт/промах/повтор, нативный lifecycle pause, localStorage). Затем публикует APK и SHA-256 в GitHub prerelease. APK не хранится в Git.

## Идея и границы

Короткий цикл «попытка → ошибка → мгновенный рестарт», понятное управление, музыкальные попадания и визуально читаемые спасения у края — гипотеза для коротких игровых видео. Это оригинальное оформление знакомой stack-механики, **не доказательство спроса и не гарантия попадания в тренды**.

Для проверки идеи: дать прототип 20–30 игрокам, измерить понятность первого запуска, число добровольных повторов, возврат на следующий день и желание делиться результатом. В этой версии трекинга намеренно нет; наблюдения собираются вручную с согласия игроков. Не стоит покупать трафик до такой проверки.

Исходные `.exe`, `.dll` и `.rar` в корне репозитория не относятся к игре, не запускались, не менялись и **не входят в APK**. Android упаковывает только каталог `web/` и собственный код/ресурсы `android/`.
