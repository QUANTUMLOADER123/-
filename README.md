# ОСКОЛ · DEV 0.30.0 / итерация 29

Одиночный офлайн 3D-survival для Android, Windows x64 и браузера. Авторский прототип, вдохновлённый добычей/стройкой Rust; **не Rust, не продукт Facepunch**. Без мультиплеера, внешних API и рекламы. Старая аркада сохранена отдельно в `web/layer/` и предыдущих релизах.

## Пакеты и проверка

[GitHub Actions → DEV29, build only](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml):
- `Oskol-Android-dev29-NO-TESTS` — `oskol-0.30.0-dev29-android.apk`, SHA-256; Android 8+, WebGL 2, актуальный System WebView. Version code 31, прежние application ID и development-подпись.
- `Oskol-Windows-x64-dev29-NO-TESTS` — portable EXE, инструкция, SHA-256; Windows 10/11 x64. Прежний каталог сохранений `%APPDATA%/oskol-survival/Local Storage`.

Артефакты скачиваются с входом в GitHub. Репозиторий публичный; автоматической публикации Release/магазина нет. Windows-пакет не подписан коммерческим сертификатом: не отключайте защиту ради запуска прототипа.

**По просьбе пользователя тесты не запускаются.** В CI только esbuild, Gradle `assembleDebug` и упаковка Electron — без unit/browser/native smoke, эмулятора и lint. Исторические тестовые исходники оставлены, но их старые результаты не являются подтверждением DEV29. Успешная сборка не проверяет игру на реальном телефоне/ПК, баланс, коллизии, FPS или Alt+Tab.

## DEV29 — боты, физическая стрельба, оружие и материалы

- NPC стреляют настоящими пулями из дула, без прямого урона через преграды. Проверяются стены, закрытые двери, перекрытия, треугольные крыши и скаты; начало луча внутри преграды считается попаданием в неё.
- Резервирование разных окон, наружные патрули, разнесённые точки сбора и прикрытия. Один строитель на дом улучшает выбранные стены/перекрытия, переносит ресурсы со склада и работает киянкой. Расходуются реальные ресурсы и сама киянка крафтится за ресурсы. Нет бесплатной смены всего дома на металл.
- Светлая человеческая модель Adventurer, цвета одежды из действительного инвентаря, костные накладки головного убора/маски/жилета/перчаток и двухзвенная IK рук к хватам оружия.
- Лутаемое тело: реальный перенос инвентаря без повторной выдачи оружия/одежды; положение, предметы и вид тела сохраняются. До 12 подробных тел в радиусе 110 м, остальные представлены мешком с тем же содержимым. **Процедурное падение и расслабленная поза, не физически симулируемый ragdoll с суставами.**
- 16 отдельных самодельных оружейных профилей/геометрий и авторских текстур металла; 32 отдельных файла выстрела из лицензированных CC0-записей. Индивидуальные интервалы стрельбы и наклоны при перезарядке. Все 155 утверждённых иконок сохранены.
- Бревенчатые деревянные стены, серые каменные кирпичи, оранжево-красный трубчатый ржавый металл, отдельная серая броня HQM (уровень 4; 2200 HP, улучшение за 12 highMetal, обслуживание/ремонт за highMetal).
- Приглушённый грунт; меньше накладывающихся плоскостей листвы, ближние тени листьев; море не рисует дорогой зеркальный проход, когда оценка видимости не находит воду, не отражает мелкую траву/подлесок, упрощает дальнюю рябь. Это структурные изменения, **не измеренный прирост FPS**.

[Подробности и ограничения DEV29](src/survival/DEV29.md). Новый мир не требуется; ревизия рельефа 14 не менялась. Предыдущие настройки графики, 3D-превью, прицелы и трещины DEV28 включены.

## DEV28 — прицелы, трещины, графика и 3D-превью

- Исправлена точка ADS механического прицела: больше не смещается внутрь ствольной коробки. Высота посадки определяется по геометрии, коллиматор/оптика расположены выше коробки, механические прицельные элементы скрыты при установке оптики. Исправлены координаты дульного среза разных пушек для модулей и вспышек.
- Повреждённая постройка покрывается **поверхностными ветвящимися трещинами**, без шейдерных дыр; до полного разрушения стена остаётся целой, включая тень и коллизии.
- **Подробные настройки:** AA выкл./FXAA/SMAA/MSAA 2×/4×/комбинированное; масштаб рендера 50–125%; текстуры ÷1/2/4/8 по стороне; анизотропия; тени выкл./512/1024/2048 и частота обновления; отражения воды и их частота; трава, декоративный подлесок, PBR-карты, дождевые частицы; лимит 30/45/60/90 кадров или без лимита. Три пресета, новый стандарт — «Баланс». **Только текстуры требуют сохраниться, выйти в меню и снова войти в мир.** При ÷8 у карты в 64 раза меньше пикселей; это не обещание 64× FPS.
- Оптимизация: пространственный отбор препятствий для LOS вместо полного перебора; обновление данных трещин только при изменении; ограниченные частоты теней/отражений; отсутствие скрытого двойного AA; 2–3 одновременных декодера вместо загрузки всех изображений сразу. Уменьшение текстур выполняется до первой отправки на GPU, исходные изображения не хранятся ради обратного переключения. Физика, конечные ресурсы, ИИ и сохранения не отключаются ради графического пресета.
- В инвентаре **настоящий 3D-рендер персонажа вместо SVG-куклы**: существующий лицензированный скелетный Adventurer, выбранные семь слотов одежды, объёмные элементы экипировки, перчатки на геометрии кистей/пальцев. Поворот перетаскиванием/кнопками, приближение. Один общий WebGL-контекст с миром; превью рисуется по изменению, а не непрерывно. Это стилизованная модель с общими семействами одежды, **не 56 новых уникальных костюмов и не тканевая физика**.

[Реализация и ограничения DEV28](src/survival/DEV28.md). Как и раньше, **без запуска игры и тестов**. Синтаксис/сборка не подтверждают внешний вид ADS, посадку одежды или прирост FPS на устройстве. Новый мир не нужен.

## DEV27 — групповые рейды, окна и спальники

- Отряд собирается у конечного склада, запасается боеприпасами/зарядами, идёт на разведку, назначает подрывника и прикрытие, затем штурмует или отступает. При тревоге дома рейд отменяется в пользу обороны. Заряды, патроны и ремонтные материалы не появляются бесплатно.
- Защитники проходят через открываемые ими двери к реальным окнам первого этажа. Коллизии соответствуют раме, подоконнику и решётке; проверка видимости остаётся обязательной. Есть распределение окон, смена позиций, приседание за подоконником, возвращение к складу за патронами и оплачиваемый ремонт в паузах обстрела.
- **Спальник:** крафт **40 ткани + 1 швейный набор**, установка атакой как другого предмета на ровный грунт/свой фундамент/крышу. **E / ВЗЯТЬ** помечает предпочтительную точку. На экране смерти выбери нужный спальник или берег. До 8 живых спальников; точка сохраняется. Разрушенные исключаются, заблокированные недоступны. Проверка места остаётся на том же этаже и не ищет точку за стеной. Возрождение без нового бесплатного снаряжения; таймера спальника нет.
- Новая индивидуальная иконка спальника по прежнему утверждённому эталону; 155 законченных иконок DEV26 не переделывались. Текущий остров и ревизия рельефа 14 сохранены: создавать новый мир ради спальников/тактики не требуется. Если жители были отключены в сохранении, сами они не добавляются.
- **Ограничения:** это экспериментальные локальные правила/планирование, не человеческий интеллект. Тактические комнаты — только первый этаж; до 6 дополнительно удерживаемых подробных домов для осад. Ограниченная навигация может не найти путь; сложные базы/тамбуры могут остановить рейд. Бой NPC между собой упрощён, а приседание процедурное, без IK/mocap. Игрового прогона и измерений не было.

[Подробности DEV27](src/survival/DEV27.md). Проверки — только статический разбор, синтаксис, компиляция и упаковка APK/EXE. Не подтверждают работу тактики, спавна, внешнего вида или FPS на устройстве.

## DEV26 — автономные отряды и полный набор иконок

- **155 исходных иконок перегенерированы** по единому выбранному эталону и подключены ко всем предметным панелям. Прозрачные WebP 256×256; меньшая дверь, естественный камень и исправленный жилет сохранены. Бронированные перчатки/сапоги заменены на современный тактический вариант. Лезвие тесака — прежний ID `metalBlade`.
- **Экспериментальные автономные жители:** лимит 0–96 при создании, по умолчанию 32, охрана РТ отдельно. Большие дома изначально заселены плотнее. Три враждующих команды, добыча общих конечных ресурсов, перенос реального лута, хозяйственный крафт, стройка, засады, обходы, отступление и рейды с расходом зарядов.
- Стартовое имущество выдаётся **однократно**. Боеприпасы/бинты/еда расходуются; после гибели фактические вещи остаются в общем мешочке. Возрождение через 180 игровых секунд — без нового снаряжения. Депо — настоящий доступный ящик. Нет дохода в меню/офлайне.
- Это **не человеческий интеллект и не проверенный в игре полноценный аналог игроков**: локальная ограниченная навигация, упрощённая NPC-печь и бой между ботами; сложные внутренние маршруты РТ могут быть недоступны. Используются существующие скелетные Swat/Adventurer с процедурной походкой/бегом и оружейной позой, не новые реалистичные люди и не mocap.
- Два новых огнестрела — **К-24 и ПДВ-40**, готовые локальные модели Quaternius CC0 с адаптацией материалов, UV, хватов и магазина. Это стилизованный Sci-Fi Modular Gun Pack, не реалистичные сканы и не полная замена всех старых моделей оружия. Четыре новых обвеса: ×8, компактный глушитель, компенсатор и барабан +75%; всего 12. Новые шесть предметов разделяют подходящие уже готовые иконки — не шесть дополнительных AI-картинок.
- **Новый мир, ревизия 14:** сильнее округлые возвышенности, больше конечных залежей руды, согласованные дороги/реки/площадки. Размер по умолчанию 1170×1170 м; выбор до 8000 м сохранён. Продолжение не переделывает прежний рельеф; для нового рельефа и выбора лимита создайте новый мир, предварительно экспортировав сохранение.

[Точные возможности и ограничения DEV26](src/survival/DEV26.md). Только статический разбор и сборка. Игра, автономное поведение ИИ, внешний вид, звук, физика и FPS **не проверялись прогоном**.

## DEV25 — обвесы, парная конопля, крупные РТ

- **E / ВЗЯТЬ — только взаимодействие.** Стрельба, удар, заряд и установка с планом — отдельная атака; E больше не проваливается в использование предмета.
- Конопля около **1,73 м**, новые колонии по **2 растения** в 0,68–1,06 м друг от друга; старые растения получают соседнее. Общая геометрия, потоковые 48-м тайлы, постоянные ID и сохранённый сбор.
- Плавно смешанные снег/лес/пустыня/берег: искривлённые границы, единый цвет миникарты и грунта, непрерывная климатическая маска.
- Вместимость стака расходников/сырья/патронов × множитель добычи. Например, дерево ×5: **5000**, патроны: **320**. Оружие, инструменты, одежда и модули по одному. Учтены рюкзак, контейнеры, печь, переработчик и загрузка сохранения.
- **4 слота обвесов**, 8 отдельных модулей, рецепты у верстака, лут и торговля. В инвентаре выбери оружие → **ОБВЕСЫ**. Снятие/замена возвращают предмет; увеличенный магазин +50% не создаёт патронов. Комплект хранится **по типу оружия**, как существующие магазин/износ; не отдельный серийный экземпляр каждой пушки.
- Прицелы holo/коллиматор/×4, глушитель, тормоз, пламегаситель, ЛЦУ (**L**), увеличенный магазин. Штатно **без бесплатного holo**, ADS по механическим. У RPG остаётся родная прицельная планка, съёмные модули несовместимы.
- Авторские детали ремонтного оружия, хват левой руки от геометрии цевья, видимые модули и продлённый магазин. Используются прежние лицензированные записи звуков, обработка глушителя; **звуки и модели Facepunch не копировались**.
- Дорожный ящик стоит на багажнике/кузове существующей машины, прежний ID и содержимое сохранены. На машинах РТ добавлены отдельные багажные ящики; они не входят в статический меш.
- **Новый мир, ревизия 13:** РТ шире в 1,5–2,2 раза; промышленная сфера на месте радарного узла — около **61 м шириной / 40 м высотой**, внутренние площадки и лестницы. Размеры резервируются до дорог/поселений. Старые миры **не переводятся** на новый рельеф и размеры РТ.
- Поверхность острова уже один меш. РТ остаются пространственными 10-м пакетами по материалам; теперь вершины индексируются без склейки UV/нормалей. Кешированные машины тоже индексированы. Двери, лут, разрушение, деревья/трава и отсечение остаются отдельными: один гигантский меш всей карты ухудшил бы отсечение.

Подробности: [`DEV25.md`](src/survival/DEV25.md). Только синтаксис и сборка; внешность, звук, физика, производительность и игра на устройствах не проверялись.

## DEV24 — 7 слотов одежды / 56 вещей и компактный лут

- **Быстрый крафт не создаётся при открытии ящиков, мешочков, шкафов, печей, переработчика, ремонтного стола и магазина.** Справа остаётся нужный контейнер или станок, а не две панели друг над другом. В обычном рюкзаке быстрый крафт остаётся; полный крафт доступен во вкладке.
- **7 настоящих слотов:** голова, лицо, тело, верх/броня, ноги, кисти, ступни. Надетые вещи хранятся отдельно от 36 слотов рюкзака/пояса. Плащ и бронежилет занимают один верхний слот; рубаха под ними — другой.
- **56 вещей всего (55 новых + прежняя кожаная броня):** кепки, шапки, ушанки, шлемы из кожи/лома/кевлара/композита, банданы, шарфы, маски; рубахи, тельняшка, худи, флис, стёганая одежда; пончо, плащи, меховой плащ, кожаные/металлические/противоударные/кевларовые/керамические жилеты; 8 вариантов брюк, 8 перчаток/наручей и 8 видов обуви.
- Надевание: выбрать вещь → **НАДЕТЬ**, двойной щелчок или перетаскивание на подходящий слот. Снятие — нажать вещь на персонаже. При полном рюкзаке снять нельзя, но заменить надетую вещь можно: старая занимает освободившийся слот новой. Ничего не выбрасывается автоматически.
- Защита от пуль, укусов и взрывов учитывается только у надетых вещей, с долями покрытия тела и общим пределом 70%. Одежда в рюкзаке не защищает. Падения, голод, жажда и утопление бронёй не смягчаются. Значения баланса не проверены игровым прогоном.
- Оригинальные векторные иконки и схематичный персонаж показывают выбранные вещи. На существующем first-person риге меняются материалы перчаток/пальцев/рукавов; без перчаток скрываются накладки и видна кожа. Это не новая полная 3D-модель тела.
- Все вещи имеют рецепты в категории **ОДЕЖДА**, продвинутые — у верстака. Одежда появляется в ещё не созданных контейнерах по тиру; 8 вещей продаются за металлолом. Уже сохранённые контейнеры не перезаполняются. В случайном луте одежда не умножается ×50; собственные хранилища и мешочки не обрезаются.
- Экипировка сохраняется в `wear24`. Прежняя автоматически действовавшая кожаная броня при чтении старого сохранения один раз переносится из рюкзака в верхний слот без создания копии. Прежние вещи и мир не сбрасываются; правило сохранения вещей после возрождения остаётся прежним.

**Новый мир не нужен.** Проверки только статические и сборочные, без запуска игры/тестов/браузера/эмулятора. Работа экипировки на устройстве, внешний вид, сенсорное управление, баланс и FPS игровым прогоном не подтверждены. [Технические детали DEV24](src/survival/DEV24.md).

## DEV23 — густые кроны и живой подлесок по биомам

- Кроны семи видов деревьев уплотнены: больше нарисованных листьев/хвои, дополнительные пучки внутри ветвей и более полные края. Силуэты разных пород сохранены.
- Лес: широколиственные кусты, хвойный молодняк и группы светлых/сиреневых цветов. Север: низкие хвойные и вереск со светлыми верхушками. Побережье: серебристо-зелёные кусты и тростник с метёлками. Пустыня: редкие серо-зелёные кусты и сухие розетки; кактусы DEV18 сохранены.
- Кусты — оригинальная непрозрачная геометрия веток и сложенных листьев, не кубы и не прозрачные квадраты. Разные масштаб, поворот и небольшие неравномерные колонии; ветер, приближённое просвечивание, затемнение при намокании. Новый туман не добавлен.

Это художественное решение для вида от первого лица, не полнотелая биомеханическая симуляция.

Новый контроллер объединяет плавное появление предмета, шаг/остановку по фактической скорости, бег с опусканием на 30°, остаточное движение при повороте, приседание, прыжок/приземление и переход в плавание. Неподдержанный предмет больше не подменяется камнем в руке.

FOV и отдача затухают плавно; бег, перезарядка, плавание и появление предмета имеют явный приоритет. HUD-крестик учитывает доступность и переход ADS. Лишний прежний цилиндрический прицел у bolt-винтовок скрывается только у held-модели.

Левая кисть меняет ориентацию между цевьём, магазином и затвором. Правая работает с ручным затвором. Пистолетный затвор и помпа движутся после выстрела.

Это существенно новая авторская first-person анимация, не mocap/AAA-ассеты. Подробности и ограничения: [VIEWMODEL14](src/survival/VIEWMODEL14.md).

## DEV13 — низкие холмы, долины, берега и новая генерация

**Новая генерация включается только при создании нового мира (`contentRevision: 6`).** Продолжение сохранений ревизий 3–5 использует прежние формулы высот, берегов, рек, площадок РТ и размещения домов. Установка APK/EXE не должна сама пересоздавать остров. Новый мир заменяет прежнее сохранение после успешного входа; отмена входа DEV11 сохранена. В меню подписана ревизия сохранённого мира.

- Убраны из новой ветки высокие шумовые гребни и добавки 165/115 м на больших картах. Вместо них — низкочастотный континентальный рельеф, широкая асимметричная возвышенность, мягкие ложбины и плавное искажение координат. Плавный `tanh` ограничивает амплитуду без срезанных плоских вершин. Это художественная генерация, **не измеренная геология и не симуляция эрозии**.
- Горизонтальный размер острова больше не тянет вверх горы пропорционально масштабу. Усиление высот ограничено 1.65×; кодовый мягкий предел — `42 × relief` метров, не измеренная высота реальной вершины. Мелкие детали имеют фиксированные мировые длины волн 125/28 м и малую амплитуду: они не превращаются в огромные бугры на 8-км карте.
- На небольших новых картах общая сетка суши продлена под ближний шельф и обе нефтеплатформы. Опоры платформ доходят до нового дна. Для новых сохранений допустимая глубина игрока/мешочков расширена до −40 м, чтобы погружение на шельф не делало сохранение невалидным. Для старых ревизий пределы прежние. Урон от глубины не добавлен; кислород остаётся прежним.
- Не круглая кромка-купол: seeded берег с мысами/вогнутыми участками, пологая пляжная полоса, широкое постепенное повышение к суше и плавно уходящий под воду шельф. Низкие каменные выходы вместо прежних высоких декоративных прибрежных силуэтов. Сам ландшафт остаётся общей геометрией для физики и изображения.
- Единое извилистое русло с плавно убывающим уровнем к морю, берегами, широкой долиной и поймой. На новых картах река есть и на малых размерах. Ширина учитывает шаг общего треугольного рельефа, чтобы канал не был заведомо уже разрешения суши. Это авторское русло/приближённая пойма, не автоматически рассчитанная сеть водосбора или симуляция жидкости.
- Новые площадки РТ отодвигаются от русла до построения домов и расширенной дорожной сети. Влияние выравнивания защищает канал/берег. Переходы вокруг площадок расширены с прежних 9 м до минимум 28 м, чтобы уменьшить искусственные крутые стены. Лагерь имеет более широкий плавный переход. Дома дополнительно исключаются из узкой береговой полосы.
- Дороги и мосты пересчитываются по общей новой высоте/реке, подходы к РТ используют их новые координаты. 20 РТ, 120 домов, соединённая дорожная сеть и отсутствие ботов в домах сохраняются как правила генерации. Проходимость маршрутов и пересечения объектов не проверялись игровым запуском.
- Графика/дождь/материалы DEV12, плавное приседание, лут и инвентарь сохранены. Старые ветки высот/рек/площадок/размещения изолированы от новых условий; схема сохранения остаётся v2, ключ сохранения/application ID/подпись APK прежние. ИИ и механика боя не перерабатывались.
- Генерация остаётся отложенной до входа на карту; новый модуль не строит мир в главном меню. Существующие порционные генерация/компиляция/отмена и кеш треугольных высот сохранены.

**Без тестов, игровых/браузерных/native/визуальных прогонов и численного прогона генератора.** Только статический разбор формул/веток совместимости, компиляция JS и упаковка APK/EXE. Не измерены реальные максимальные высоты, уклоны, время входа, FPS; не проверены все seed, пляжные спавны, проходимость мостов/дорог или отсутствие артефактов. Это существенная новая итерация процедурного острова, не обещание фотореализма.

## DEV12 — поверхности, освещение, вода и дождь

- **6 новых авторских AI-поверхностей, 18 карт:** дерево, кладка, ржавеющий металл, бетон, лесная почва, асфальт. Цвет/микрорельеф — 1024², совмещённые AO/roughness/metalness — 512². Это художественно полученные материалы, не измеренные PBR-сканы. Нормали и шероховатость приблизительные; источники, SHA-256, каналы и ограничения: [pbr12/README](web/assets/pbr12/README.md).
- Дома, строительные уровни, ящики и РТ получают новые поверхности. Ржавчина локально уменьшает металлические блики. Дорожная текстура привязана к мировым метрам и не вытягивается по длине дорог; дорожная геометрия/проходимость не менялась.
- Ландшафт смешивает почву, скалу, песок и снег по уклону/высоте/существующему биому, с деталями нормалей и крупными цветовыми вариациями. На среднем/высоком качестве скальная diffuse-карта проецируется с трёх сторон. **Высоты/коллизии, расположение домов, seed/ревизия карты и сохранения не меняются.**
- Переработаны цвет неба, освещение, движущиеся слои облаков с приближённым затенением и закат. Отражённое освещение снимается с текущего неба и обновляется с ограниченной частотой. **Наземного тумана нет**; подводный туман остаётся.
- Дождь теперь состоит из инстансированных полос с ветром и разной длиной, а не одного набора тонких линий. Локальная карта высот 80²/48 м отсеивает капли ниже земли/воды/дорожных настилов/крыш; кольца брызг возникают на этих поверхностях. Это приближённая растеризация, не трассировка: маленькие проёмы и сложные крыши могут давать артефакты. Под крышей не выключается весь дождь снаружи.
- Намокание постепенно затемняет и сглаживает материалы; после дождя поверхности сохнут медленнее. Накрытые поверхности в локальной зоне учитывают карту крыш. Новая погода не меняет добычу, здоровье, проходимость или физику.
- Море/река: Fresnel-блики, анимированные микроволны, прозрачное мелководье, глубинный цвет и пена побережья. **На высоком качестве** у моря добавлено реальное дополнительное отражение сцены относительно уровня моря; 512 px по ширине, периодическое обновление, только при подходящей высоте камеры и поддержке HDR. Это не SSR/RT и не отражения рек на разных высотах; волновая физика не добавлена.
- Деревья сохраняют готовые модели Quaternius; добавлены текстурная кора из уже атрибутированного Babylon-набора, UV стволов, вариация окраски, подсветка листвы на просвет и ветер с соответствующей деформацией теней. Трава получила градиент от основания к кончикам и общий с дождём ветер.
- Высокое + максимальное сглаживание + HDR: сдержанный bloom ярких источников. На «Балансе»/«Экономно» он выключен. Разрешение новых карт определяется при входе: 512 в экономном и 1024 в остальных режимах. Если переключить режим во время игры, для смены разрешения текстур нужно выйти и войти.
- **Настройки → Погода:** автоматический 12-минутный цикл, ясно, облачно, дождь или ливень. Выбор сохраняется как настройка, не меняет формат мира. Можно увидеть дождь без ожидания естественной смены погоды; намокание всё равно нарастает постепенно.
- Сохранены быстрый HTML-старт меню DEV11, подготовка/компиляция под экраном входа, отмена с сохранением прежнего мира. Карта цвета глубины воды тоже строится отменяемыми порциями. При выходе освобождаются отражения, дождевые ресурсы, дополнительные shadow-материалы, инстанс-буферы и карты теней; кеш пропов сбрасывается. Боты/оружие/лут/плавное приседание не перерабатывались.

**Без тестов, браузерного/игрового/визуального/GPU/native/аудио-прогона.** Только авторинг ассетов, статическое чтение, компиляция и упаковка. Компиляция JS не проверяет GLSL на реальном GPU. Качество изображения, ошибки укрытия от дождя, отражения, расход памяти, FPS и нагрев на устройствах не измерены; это итерация прототипа, не обещание AAA/фотореализма.

## DEV11 — сразу меню, полная подготовка при входе, отмена и иллюстрации

- **Холодный запуск — сразу главное меню.** `boot()` больше не вызывает `configureMap`, `IslandWorld`, WebGL/PMREM, загрузку моделей/текстур/аудио или генерацию травы. Тяжёлый движок вынесен esbuild в динамический `web/chunks/world-*.js` и импортируется только после начала входа. В меню читаются настройки/валидируется локальное сохранение и отображается HTML/CSS; декодирование сохранения больше не ищет пляж. Настройки, журнал и создание мира доступны без 3D.
- **Вся подготовка карты — под экраном входа:** дороги/поселения/рельеф, модели, текстуры, общая растительность, восстановление сохранения, ближайшие подробные дома, завершение локальной травы возле игрока, компиляция материалов окружения/рук/оружия, прогрев первого кадра и SMAA, декодирование записанных звуков. Отдельные работы рельефа и травы разбиты на отменяемые порции. Симуляция/урон ИИ при прогреве не запускаются. Это более полная подготовка, а не искусственная задержка ради длинной полосы; длительность зависит от размера мира и устройства. Дальние детали по-прежнему подгружаются по мере движения — весь остров не держится в максимальном LOD.
- **«Остановить вход» справа снизу**, Escape и Android «Назад»: `AbortController` прерывает сетевые чтения локальных моделей/текстур/звуков и останавливает последующие этапы. Меню показывается при отмене; повторный вход блокируется на время завершения уже начатых декодеров/GPU и освобождения временного мира. Внутри одной синхронной JS-операции или встроенного декодера мгновенная остановка не обещается. `Promise.allSettled` не позволяет позднему результату парсера попасть в уже уничтоженную сцену. При отмене нового мира прежнее сохранение не перезаписывается.
- При выходе в меню 3D-мир освобождается, не анимируется и не рисуется за меню. Следующий вход снова проходит подготовку. Чтение предпросмотра больше не генерирует карту: в меню только кешированная JPEG-миниатюра после успешного входа либо честная заглушка до первого входа.
- **8 новых авторских AI-иллюстраций**: ночной дозор (двое в броне идут к камере, зелёные ПНВ и лазеры), зимний перевал, сухая развилка, дождливая ТЭЦ, нефтеплатформа в шторме, лесная база, маяк на рассвете и огни у бункера. Первый фон — ночной дозор, остальные перемешаны; смена примерно каждые 10 секунд или кнопкой «Следующий фон». Это концепт-арт, не игровые скриншоты, что подписано на экране. Нет ресурсов Facepunch. [Список и SHA-256](web/assets/ui11/README.md).
- Плавное приседание, дорожная сеть DEV10, скрытые значки домов, предметы/инвентарь/плавание и прежний ИИ сохранены. Схема сохранения/application ID/подпись APK не менялись.

**Без тестов и игрового/браузерного/визуального/native прогона.** Только статическое чтение, компиляция JS/CSS и упаковка APK/EXE. Фактические секунды запуска/входа, отзывчивость отмены на устройстве и отсутствие подгрузочных рывков не измерены.

## DEV10 — меню, загрузка, HUD и развилки

- Главное меню перестроено по визуальным референсам Rust, включая верхнюю навигацию обновления 2025 года: тёмные прямоугольные панели, вкладки «Главная»/«Играть», зелёная кнопка сессии, журнал/настройки, нижняя панель локального игрока. Вместо неработающих магазина/мультиплеера — настоящий браузер одного локального мира, seed/размер/добыча/день и предпросмотр текущего рельефа, дорог и РТ.
- Загрузка приложения, новой карты **и сохранённой игры** использует общий полноэкранный интерфейс: этапы ресурсов/карты/снаряжения/графики, монотонный процент, прошедшее время и переключаемые полезные советы. Процент меняется по загрузке ассетов и фактическим строительным этапам, не по таймеру. Между тяжёлыми этапами генерации браузеру даётся возможность нарисовать статус; графическая компиляция не выдаётся за уже завершённую игру.
- HUD: шесть серых полупрозрачных слотов пояса снизу по центру, голубой выбранный слот, отдельные счётчики, показатели здоровья/воды/еды справа, более читаемые компас и взаимодействие. Под мобильные кнопки выделены отдельные зоны; кислород, плавание, перезарядка, безопасные зоны, строительный план и трёхзонный инвентарь сохранены. Данные еды/воды остаются настоящими значениями этой игры, а не фиктивными числами Rust.
- С карты убраны **автоматические метки 120 домов и своих фундаментов**. Физические дома не удалены; РТ, игрок, лагерь/передатчик и ручные флажки остаются. Предпросмотр в меню также не раскрывает дома.
- Вместо одного кольца и одной внутренней дороги — детерминированная сеть: **40 внутренних связей** (пять нерегулярных рядов и столбцов), **8 подключений к кольцу**, три подключения к центральной дороге, соединённые концы старой центральной дороги, подъезды к удалённым наземным РТ и местным группам домов. Каждая ветка — отдельный непрерывный путь, без случайных прямых перемычек между концами разных дорог. Подъезды заканчиваются у периметра РТ; новые пути обходят защитные области существующих домов/лагеря. Морские платформы остаются морскими.
- Узлы врезаются в настоящие сегменты, а не заканчиваются рядом; случайные пересечения новых маршрутов со старой центральной дорогой тоже разбиваются на общие узлы. Примыкания получают общую высоту и опорные поверхности; близкие узлы объединены по высоте. На речных пересечениях остаются мосты DEV08; ограждения не перекрывают примыкания. Новый придорожный лут использует прежние типы/правила выпадения.
- Совместимость: **сначала** формируются прежние дома с историческим исключением двух старых дорог, **потом** расширяется сеть. Координаты/порядок/ID/параметры 120 домов, seed и ревизия рельефа не переигрываются. Старые придорожные кластеры создаются по исходным выборкам, поэтому добавленные узлы не сдвигают их ID/позиции. Свой инвентарь/постройки/контейнеры не обнуляются; новые дороги могут оказаться рядом с уже построенной базой.
- Боты/ИИ/охрана РТ **не перерабатывались**. Плавное обратимое приседание DEV09 сохранено.
- Весь интерфейс офлайн: Roboto Condensed с кириллицей (SIL OFL 1.1, локальный файл/лицензия), собственный AI-концепт-арт с явной подписью, без скриншотов/логотипов/ассетов Facepunch. Это визуальная адаптация для одиночной игры, **не заявление о пиксельной идентичности** Rust. [Источники референсов и ресурсов](web/assets/ui10/README.md).

**Только статическое чтение и компиляция/упаковка.** Игровой, браузерный, визуальный, native/эмуляторный прогон, FPS и проходимость новых перекрёстков на устройстве не проверялись. Успешный CI не подтверждает отсутствие игровых ошибок.

## DEV08 — вода, столкновения, оружие и окружение

### Физика и управление
- `state.terrainHeight` теперь интерполирует **те же треугольники, что рисуются**; решётка не меняется при смене графики. Кэш вершин ограничен размером сетки и пересоздаётся по seed/масштабу/ревизии. Персонаж и трава больше не используют отдельную несовпадающую аналитическую поверхность.
- Мотор: подшаги до 1/120 с, контакт ног с рельефом, небольшие ступени, торможение/воздушное управление; отдельные режимы ходьбы/плавания. Разделены верх пола и потолок снизу — пловца не должно вытягивать наверх через мост. Коллизии машин составлены из повёрнутых корпусов/кабин, капот и крыша имеют опорные поверхности.
- Плавание с плавучестью, вертикальной скоростью, подъёмом и погружением: **Space — вверх, Ctrl — вниз**, направление взгляда управляет движением вперёд. На телефоне можно держать прыжок; присед используется для погружения. На берег выходят обычным движением.
- Повреждение от глубины/положения ног убрано. Воздух расходуется **только когда камера/голова под водой**, запас 28 секунд. После исчерпания — удушье 8 HP/с; на поверхности воздух восстанавливается. Новый источник урона и кислород валидируются/сохраняются. Под водой цвет/видимость меняются, на суше тумана нет.
- Дороги подразделены на короткие сегменты и имеют опорную поверхность. Через реку формируется поднятый мост с подъездами, настилом, стойками, перилами, опорами и коллизиями вместо асфальта по воде. Новая расстановка придорожных групп использует новые ID; прежний подобранный дорожный лут не мигрируется на новые группы.
- Tab повторным нажатием закрывает инвентарь; I тоже переключает его. Закрытие отменяет незавершённое перетаскивание. При загрузке сохранения внутри новой коллизии ищется ближайшая свободная точка, без сброса инвентаря/мира.

### Лут и оружие
- Бочки оставляют **мешочек с содержимым на земле**, без автоматической выдачи в карманы; содержимое и множитель сохраняются. Это не отдельная rigid-body симуляция каждого кусочка металлолома. Один мешок на источник, как для уничтоженных ящиков.
- Огнестрел, инструменты, расходники и размещаемые предметы автоматически идут сначала в свободные слоты пояса, затем в рюкзак. Материалы автоматически пакуются только в рюкзак. Существующие предметы пояса не вытесняются и не расходуются от самого подбора.
- Пули имеют скорость, гравитацию, сопротивление, время полёта, максимальную дальность и снижение урона. Вместо мгновенного попадания выполняется пересечение пройденного сегмента с рельефом/целями/укрытиями. Дробовики выпускают 8 дробин. Выстрелы четырёх RT-охранников тоже проходят эту систему; домовыми ботами мир не заселяется.
- Профили скорости/дальности: пистолеты 250–280 м/с / 180–200 м, ПП 290 / 230, дробь 180–190 / 85–90, винтовки 380–680 / 400–850. Это игровые параметры, не утверждение о достоверной судебной баллистике. Гравитация действует сразу, прицел пристрелян примерно на 50 м.
- Обычная ракета 55 м/с, HV 95, падение 4,4 м/с² и сопротивление. Ракета поворачивается по скорости; столкновения проверяются вдоль сегмента, включая повёрнутые коллизии мостов/машин.
- Объёмные голографические прицелы с рамкой, стеклом и светящейся маркой. ADS совмещает оптический центр с направлением камеры; центральный HUD-крест в ADS скрывается. У ракетницы боковой прицел со шкалой 50/100/150/200 **для обычной ракеты** и видимый цикл открытия казённика / подачи ракеты / закрытия, без «выпадающего магазина».
- Руки используют существующие skinned-пальцы с новыми ограниченными углами, разными рамками захвата, опорой под цевьём и отдельным положением указательного пальца; плечо/предплечье/кисть связаны костями и аналитическим двухзвенным IK. Нет заявления о полноценной физической контактной симуляции каждого пальца, mocap или гарантированном отсутствии пересечений всех поз.

- Детерминированная по seed/игровому времени смена ясной погоды, облачности и дождя: плотность облаков, свет, осадки, подпись в HUD. На суше нет тумана. Дождь скрывается под крышей/под водой. Это визуальная погодная система, без обещания записанной дождевой атмосферы.

## Исправления DEV06 по замечаниям пользователя

1. **120 домов вместо 1200.** Сохраняются 1–10 этажей, несколько дверей и единый материал дома 40/40/20. Снижен лимит полной подгрузки: 8/16/28 домов для low/medium/high; дома с активными зарядами временно удерживаются дополнительно.

Новые мешочки раздвигаются по свободным местам и опускаются на оставшиеся опорные поверхности. Старые уже объединённые мешочки нельзя восстановить по исходным ящикам — такого разделения в старом сохранении нет. Пустой ящик не создаёт пустой мешок. MSAA + SMAA и ручной облегчённый режим оставлены. Измеренного прироста FPS нет — игровых прогонов не было.
5. Руки используют согласованные оси запястий без больших встречных yaw/roll-поворотов. Хваты привязаны к рукояти/цевью, предплечья подходят к кистям с соответствующих сторон. Инструменты больше не имеют постоянного бокового завала. Это исправление процедурных поз, а не сканы рук.
6. **Спринт:** оружие, инструмент, факел, план и заряд плавно опускаются на **30° вниз**. Пока идёт спринт или предмет ещё поднимается, нельзя стрелять, бить, метать заряд, использовать предмет или начинать перезарядку. Прицеливание отключается. Обычная ходьба не блокирует действия.
7. **Ракетницы в домах:** добавлены в пул военных ящиков. У каждого шестого по ID неразграбленного дома в одном верхнем ящике назначен тайник с ракетницей и ракетами. В остальных элитных/военных ящиках — случайный шанс. Максимум одна пушка на случайный ящик сохранён; уже обысканные ящики не перезаполняются задним числом.
8. **Интерфейс по приложенным Rust-референсам:** персонаж крупно слева, справа от него реальные показатели и снизу ряд экипировки; инвентарь 6×5 и пояс 6 по центру, быстрый крафт и добыча одновременно справа. Прозрачные серо-оливковые квадратные слоты, крупные иконки без мелких подписей поверх изображения, количество в углу; печь, торговля и обслуживание шкафа используют правую колонку. Отдельные предметы одежды/создание команды не симулируются: броня действует по прежнему правилу наличия в инвентаре, пустые места экипировки декоративны. Портрет существующего CC0-персонажа теперь 384×640 и в полный рост вместо 96×96. В портретном узком окне панели перестраиваются, в альбомном остаются три зоны.
9. **Прицел:** центральная точка, четыре контрастные тонкие риски с чёрным контуром, изменение зазора при движении/приседе, отдельный hit marker. В ADS остаётся точка; при спринте/поднятии оружия, стройке и открытом меню прицел скрыт. Трассер заканчивается в фактической точке попадания луча, а не в высоте земли под верхним этажом.

Сохранены 20 ранее отдельно AI-сгенерированных иллюстраций; остальные 68 — индивидуальные авторские векторные иллюстрации, не общие белые пиктограммы и не 68 AI-генераций. Источники SVG, происхождение и SHA-256: `web/assets/items/`.
- ×2…×50 **не размножают топоры, кирки, киянки, оружие и отдельное снаряжение**: максимум одна штука каждого такого типа на случайную выдачу. На ящик по-прежнему максимум одна пушка суммарно.
- Патроны и ракеты ограничены **одним стаком каждого типа (64)**. Ресурсы/компоненты получают множитель, но не более одного ресурсного стака каждого типа (1000); еда/медикаменты/метательная взрывчатка — до 20. Крафт, магазин и переработка не получают повторного множителя.
- Уже созданные случайные контейнеры нормализуются при загрузке/открытии. **Свои ящики, шкафы, мешочки и уже взятый инвентарь не обрезаются.** При переносе в собственный ящик можно хранить несколько инструментов и стаков.
- Бочки стоят **вокруг** сгоревших машин/грузовиков/мусора с угловым разбросом, а не в одну линию. Для каждой бочки независимый детерминированный бросок: усовершенствованная **60%**, обычная **20%**, нефтяная **20%**. Это вероятности, а не требование ровно 6/2/2 в любой десятке.

### Дома, рельеф и оптимизация
- Генератор рассчитан на **120 домов**, в десять раз меньше DEV05, с **1–10 этажами**, внутренними лестницами, проёмами между этажами, несколькими дверями, шкафом и ящиками. Домовых ботов нет; четыре охранника опасных РТ сохранены.
- Один строительный материал на весь дом: **дерево 40%, камень 40%, железо 20%**. Нет прежнего чередования камня и металла по деталям одного дома. Вероятности следов рейда 25% и остаточного лута 50% сохранены.
- Дальние дома — три инстансированных набора силуэтов по материалам. Полная геометрия, коллизии и взаимодействия подгружаются только у ближайших домов: до 8/16/28 по качеству, постепенно, с выгрузкой удалённых. Повреждения, лут и состояние открытых дверей сохраняются при выгрузке. Это не 120 одновременно детализированных домов.
- Геометрии/материалы домов переиспользуются, стены/перекрытия инстансированы. Добавлены пространственный индекс опорных поверхностей и кэш уничтоженных ID, чтобы движение не перебирало все этажи карты на каждом подшаге.
- Новый рельеф: гребни, несколько холмов/массивов и мелкие неровности поверх прежних гор и реки. Фундаменты подгоняются по углам, опоры доходят до земли, входные ступени учитывают высоту склона.
- **Максимальное сглаживание по умолчанию:** MSAA до 8 samples, но не выше фактически поддерживаемого форматом устройства, плюс SMAA. Ландшафт и руки проходят один сглаживаемый кадр. В настройках есть стандартный режим без постобработки для снижения нагрузки. Максимум сглаживания тяжелее для GPU; обещаний прироста FPS нет.

### Взаимодействия и разрушение
- На ПК перетащи свой слот и отпусти **вне окна инвентаря** — предмет выбрасывается. На Android удержи слот 0,28 с и перенеси; обычный вертикальный свайп до удержания продолжает прокрутку. Половина стака учитывается. Перенос внутри окна/в печь/ящик остаётся переносом, а не выбрасыванием.
- Подрывной заряд и взрывная сумка **приклеиваются к поверхности при столкновении**, сохраняют локальную точку/поворот на открывающейся двери, затем взрываются по запалу. При разрушении опоры отклеиваются и падают. Гранаты не клеятся, а отскакивают. Упрощённая физика, не полная баллистика.
- При сносе фундамента рушатся потерявшие опору стены, перекрытия, двери, шкаф и установленные предметы. Для своей постройки проверяется связность опор; у процедурного дома детали привязаны к несущему фундаменту. Каскад может затронуть все этажи.
- Содержимое своих ящиков/шкафов/печей и рухнувших случайных ящиков переносится **без множителя** в мешочки с ручным открытием как лут-контейнера. Печь отдаёт также входы, топливо и выходы. Мешочки отличаются от деревянных ящиков и сохраняются.

### Руки, звуки, поверхности
- Вместо набора отдельных шаров/капсул — непрерывные меши ладони/запястья/рукава и **скелетные пальцы**. Разные хваты камня, инструмента, факела, плана, длинного оружия, пистолета и заряда; поддерживающая рука и движение при перезарядке. Это собственные процедурные модели/позы, не AAA-скан рук и не mocap.
- С DEV07 локальные записанные PCM-эффекты: разные выстрелы пистолета/винтовки/ПП/дробовика/ракетницы, перезарядка, взрыв, обрушение, двери, шаги, приземление и падение предметов. Громкость посадки зависит от скорости, шаги различают поверхности. Падение с большой высоты теперь причиняет урон с отдельным объяснением.
- Деревянные ящики со створками/планками, железными обвязками и замком; шкафы с петлями/запором; авторские поверхности досок, каменной кладки, лоскутного металла с ржавчиной/заклёпками и ткани. Изучены визуальные референсы Rust, **чужие игровые текстуры/модели/записи звука не включены**. Синтетические звуки DEV05 заменены записями CC0; офлайн-обработка — `scripts/prepare-audio07.py`. Полное происхождение в `web/assets/audio/CREDITS.md`.

## Сохранённые механики

Дороги, биомы на карте, день/ночь, лодки/нефтеплатформы, свои отметки и рюкзак с ручными переносами сохранены.

## Управление и сборка

WASD/стик — движение; мышь/свайп справа — обзор; Shift/кнопка — бег, Ctrl/CTRL — присед; Space/кнопка — прыжок; ЛКМ/F/удар — атака, E/действие — взаимодействие; I/Tab — рюкзак, C — крафт, B/ПКМ с планом — стройка, M — карта; R — перезарядка/поворот, Q/Z — высота фундамента; ПКМ с оружием — прицел; 1–6 — пояс. F11 — полный экран Windows. Android: Back — пауза/закрытие окна.

```sh
npm ci
npm run build
npm run dev             # 0.0.0.0:3000
npm run build:windows   # Windows host
cd android && gradle --no-daemon :app:assembleDebug  # SDK35, JDK17, Gradle8.13
```

Лимиты: один активный мир, 400 своих элементов, 10 000 мешочков, ограниченное число детальных домов одновременно; физика/ИИ/структурная связность упрощены. Не заявляется проверенная проходимость всех этажей, безошибочная мобильная раскладка или стабильный FPS: **runtime-тесты DEV07 не запускались по просьбе пользователя**. Лицензии прежних ассетов: `web/assets/licenses/`; оригинальные новые текстуры, модели, иконки и звуки снабжены исходниками.
