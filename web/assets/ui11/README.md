# ОСКОЛ DEV15 — галерея меню и загрузки

Восемь отдельных оригинальных AI-иллюстраций для игры: семь сохранены из DEV11, ночной дозор повторно сгенерирован и обработан для DEV15 2026-11-04. **Это концепт-арт, не скриншоты игрового процесса и не обещание такого качества 3D-графики.** На экране есть соответствующая подпись. Нет извлечённых изображений, логотипов, персонажей или моделей Rust / Facepunch. Все элементы интерфейса — настоящий HTML/CSS поверх фона.

Первый фон в меню и при входе — исправленный тёмный ночной дозор. Остальные семь перемешиваются. После 12 секунд показа новый фон за 2.6 секунды накладывается поверх непрозрачного предыдущего, без одновременного исчезновения обоих слоёв. Добавлено медленное панорамирование; текст/кнопки неподвижны. Галерея работает в главном блоке меню и на экране загрузки, без создания 3D-мира в меню.

Следующая картинка декодируется заранее; JS удерживает только текущую/следующую декодированные иллюстрации. При ошибке остаётся прежняя. Кнопка «Следующий фон» ждёт конца перехода. Сеансы остановлены при уходе/отмене, фоновые вкладки приостанавливают движение и таймеры, `prefers-reduced-motion` отключает движение/переход. Никаких сетевых галерей или телеметрии. Плавность в игре на устройстве не проверялась.

Промпты: самостоятельные широкоформатные реалистично-живописные сцены северного острова, без надписей/брендов/интерфейса, с тёмной нижней областью под загрузочную панель. У ночного сюжета — два анонимных персонажа в самодельной броне, зелёные окуляры ПНВ и лазерные лучи, без стрельбы/ранений; остальные сюжеты — отдельные окружения ниже.
