ОСКОЛ 0.9.0 DEV07 · СБОРКА БЕЗ ПРОГОНА ТЕСТОВ
Windows 10/11 x64. Запустите portable EXE. F11 — полный экран.
Сохранения: %APPDATA%/oskol-survival/Local Storage. Игра офлайн.
WASD — движение; Shift — бег вперёд; Ctrl — присесть; Space — прыгнуть.
ЛКМ/F — атака; E — действие; ПКМ — прицел / круг строительного плана.
I/Tab — рюкзак; C — крафт; B — план; M — карта; 1–6 — пояс.
R — перезарядить/повернуть; Q/Z — высота фундамента.
Перетаскивание слота за пределы окна инвентаря выбрасывает его в мешочек.
Случайный лут: максимум 1 инструмент каждого типа, 1 стак каждого типа патронов, 1 пушка на ящик.
Свои хранилища и мешочки не обрезаются. Все 88 предметов имеют цветные иконки.
120 домов по 1–10 этажей; детально подгружаются ближайшие, дальние упрощены.
Клеящиеся заряды, каскад опор, мешочки после обрушения; новые руки/звуки/поверхности.
Максимум сглаживания включён: доступный MSAA + SMAA. При нагрузке выберите стандартное в настройках.
Новый рельеф — только в новом мире; старый рельеф сохранён для совместимости своей базы.
Сборка не проходила игровых/native-тестов DEV06. FPS, коллизии и Alt+Tab на вашем ПК не измерены.
Это оригинальный прототип, НЕ Rust и не продукт Facepunch. Модели/физика/ИИ упрощены.
EXE без коммерческой подписи. Не отключайте защиту системы; при сомнениях собирайте из исходников.

DEV06: один разрушенный ящик — отдельный мешочек. Старые объединённые мешки остаются как были.
Новый инвентарь: персонаж слева, 6×5+пояс по центру, крафт и лут справа.
Спринт опускает предмет на 30 градусов и блокирует действия до поднятия оружия.
Ракетницы: военные/элитные ящики и верхний тайник каждого шестого неразграбленного дома.
Бочки наклоняются по рельефу. Переработаны прицел, хват рук и трассеры попаданий.
Добавлены пространственный отбор целей и ограничение частоты теней. Прирост FPS не измерен.

DEV07 — ЗВУК: старые синтетические выстрелы заменены записями CC0.
90 клипов, варианты без повторения, фазы перезарядки, шаги/удары по разным материалам.
В настройках: общая громкость, эффекты, шаги. Начните с умеренной громкости устройства.
У NPC/взрывов есть расстояние и стереоположение; звук останавливается при паузе/сворачивании.
Никаких аудио из Rust. Подробные авторы — web/assets/audio/CREDITS.md в исходниках.
Игровое прослушивание/тесты DEV07 не проводились по просьбе пользователя.
