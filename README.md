# ОСКОЛ · DEV 0.5 / тестовая итерация 03

Самостоятельный **одиночный 3D-survival с ботами** для Android, Windows и браузера. Вдохновлён циклом добычи/стройки Rust, но не содержит кода, моделей, логотипов, карт или аудио Facepunch. Не полный Rust и не финальная версия: проект предназначен для следующих итераций по результатам тестирования.

**Сборки для тестирования:** [GitHub Actions → Oskol test builds](https://github.com/QUANTUMLOADER123/-/actions/workflows/android.yml). После успешной сборки в Artifacts есть `Oskol-Android-dev03` (APK) и `Oskol-Windows-x64-dev03` (portable EXE, инструкция и SHA-256). Для скачивания Actions artifacts нужен вход в GitHub. Автоматической публикации GitHub Releases, магазина или сервера нет. **Репозиторий публичный — исходники в этой ветке публичны.**

Предыдущая аркада «ЕЩЁ СЛОЙ» сохранена в `web/layer/`, её APK в старых релизах не является сборкой ОСКОЛа.

## Новое в DEV 0.5

- **Свой ящик для вещей:** крафт → установка → 12 слотов, перекладывание в обе стороны, постоянные остатки. Пустой ящик игрока остаётся; опустошённый случайный лут-ящик исчезает и после загрузки не возвращается.
- **Печь с собственными шестью слотами:** древесина, два входа руды, три выхода. Одна руда за 4 игровые секунды, одна древесина на 8 секунд горения. Металл/сера и уголь остаются в печи, пока явно не заберёшь. Плавка работает и при открытом интерфейсе печи; игра в общем меню и в фоне приостановлена. Мгновенные рецепты переплавки удалены.
- **Строительный план в руке:** B / ПКМ с планом → выбрать фундамент, стену, дверь или крышу → поставить за ресурсы из рюкзака. Отдельные стены/фундаменты не крафтятся. Первый уровень — ветки/солома; киянка улучшает до дерева, камня и металла. Подъём фундаментов и привязка сохранены.
- **Семь видов огнестрела:** самодельная винтовка, пистолет, револьвер, ПП, дробовик, автомат, болтовая винтовка. Свои ёмкости/темпы/урон, винтовочные и пистолетные патроны, дробь; автоматический огонь у ПП/автомата. Добавлены еда, аптечный шприц, топливо, верёвка, швейный набор, шестерни и пружины для лута/рецептов. Это не система электричества или топлива для двигателя лодки.
- **80% шанс ровно одного огнестрельного предмета максимум на ящик.** При успешном броске одна пушка в одном слоте, при неуспешном — ни одной. ×2…×50 умножают ресурсы/патроны, **никогда количество оружия**. Содержимое сохраняется, повторного броска при открытии нет.
- Более густая потоковая трава из изогнутых травинок (3/5/7 лопастей по качеству), собираемая конопля → ткань; заметнее снежная и пустынная зоны с отдельной растительностью/покрытием.
- **Четыре гребные лодки на берегах и две морские нефтеплатформы**, теперь 12 РТ отдельно от шести баз. У платформ есть палуба, нижний причал, лестница и лут. Это небольшие авторские прототипы, не копии нефтянок Rust. Лодка: E — сесть, WASD/стик — грести, E возле берега/причала — выйти; в открытом море выход отклоняется.
- Пространственный индекс коллизий 16 м, реже обновляемый дальний ИИ, отключение удалённых предметных моделей, кэш локальных 3D-иконок. Это оптимизации, **не измеренный FPS телефона**.
- **Исправлена ложная потеря HP в сухом лагере:** прежняя проверка воды распространяла реку на всю ширину карты. Теперь проверяется локальный водный канал и реальное положение ног. Источник последнего урона показан; сообщение смерти больше не скрывает причину. У ботов сохранены ограничения обзора/видимости/реакции и безопасная стартовая зона.
- Потеря фокуса сбрасывает ввод и ставит паузу; «Продолжить» снова захватывает мышь. Для Windows добавлен обработчик возврата фокуса, подавлен начальный скачок мыши после захвата. Это проверено в браузере, физический Alt+Tab на пользовательском ПК ещё нужно проверить.
- Переработаны инвентарь, панель выжившего, 3D-миниатюры, пояс, крафт, выбор строительства, лут, печь и HUD. Для компоновки изучены скриншоты Rust; чужие скриншоты/ассеты в игру не включены. В landscape 844×390 топливо, входы и выходы печи видны одновременно; рюкзак прокручивается.

## Что есть в этой итерации

- Остров с рельефом, морем, текстурированной растительностью и светлым процедурным небом без тумана. 31 загружаемых моделей, уровни детализации деревьев, инстансинг травы, тени, анимированный волк и скелетные модели скитальцев.
- Перед новым миром: размер **650×650 / 910×910 / 1170×1170 / 4000×4000 / 8000×8000 м** (габариты острова вместе с берегом), добыча **×1 / ×2 / ×5 / ×10 / ×50**, сложность ботов и зерно. Рельеф и распределение ресурсов детерминированы. Компоновка РТ авторская и масштабируется; это не полностью процедурные города.
- **12 разных РТ:** Чёрный маяк, Порт «Север», заброшенный аэродром, ТЭЦ-04, каменный карьер, радарный узел, водоочистка, последняя заправка, свалка «Ржавчина», Бункер 17, малая и большая морские нефтеплатформы. Разная архитектура и таблицы лута. Карта отмечает посещение.
- Замкнутая островная дорога, сквозная ветка, придорожные ящики и разрушаемые бочки. Множитель применяется один раз к ресурсам/воде/патронам из ящиков; пушки не умножаются. **Крафт и переплавка не умножаются повторно.**
- Дерево, камень, металлическая и серная руда, волокно, ягоды, металл, сера, уголь, порох, патроны. Топор и кирка ускоряют профильную добычу.
- Фундамент 3×3, стены, вход с дверью, крыша, костёр, печь, верстак. Привязка к сетке/краям, проверка суши, ресурсов, склона и занятости. Нельзя строить на РТ, дороге и чужой базе.
- Киянка: **ветки → дерево → камень → металл**, оплата ресурсов, повышение HP, ремонт и демонтаж. Элементы разрушаются; чужие двери можно вскрывать инструментом или зарядом.
- **6 баз, 16 человеческих ботов:** два скитальца на базе и охрана четырёх опасных РТ. Патруль, подход к дереву, условная добыча в хранилище базы, возвращение и защита. Боты стреляют при видимости, реагируют на атаку своей группы и могут повреждать преграду игрока. Вскрытая база позволяет забрать ящик.
- Семь огнестрельных предметов с конечным магазином, перезарядкой и расходом своего боезапаса; броня; мгновенно срабатывающий прототип заряда. Верстак нужен рядом для сложных рецептов; плавка — только в собственной печи.
- Голод, жажда, здоровье, бинт, еда/вода, бег/выносливость, прыжок, пауза при сворачивании.
- Локальное сохранение: мир/зерно/множитель, позиция, инвентарь, состояние залежей, исследованные РТ, ящики, постройки, улучшения, повреждения баз и HP ботов. Автосохранение примерно каждые 15 игровых секунд, «Сохранить сейчас», «Сохранить и выйти», восстановление предыдущей резервной копии и автоматическое восстановление при повреждённом основном файле. Новый мир требует явного подтверждения.

## Установка

### Android

Скачай artifact Android и распакуй ZIP. Открой `oskol-0.5.0-dev03-android.apk`. При запросе разреши установку из выбранного файлового менеджера. Не отключай Play Protect. **APK debug-подписан**, не является магазинной production-сборкой. Android 8+ с актуальным System WebView/Chrome (Chromium 100+), WebGL2/GLES3. Ориентир — мощный телефон; реальный FPS ещё нужно измерять на твоём устройстве. При тормозах начни с «Баланс» или «Экономно».

Для повторных тестовых обновлений используется **один публичный development-ключ** (`android/dev-signing/`). Это позволяет устанавливать следующие APK поверх этой версии с сохранением прогресса. Это не секрет и не защита подлинности: такой ключ нельзя использовать для production. Скачивай APK только из собственной проверенной сборки, сверяй SHA-256. Удаление приложения удаляет сохранение; очистка данных WebView/приложения тоже.

### Windows

Скачай artifact Windows, распакуй и запусти `oskol-0.5.0-windows-x64.exe`. Windows 10/11 x64, WebGL2-совместимый GPU/драйвер. Это unsigned portable Electron-приложение, Windows может показать предупреждение. Не отключай защиту системы. F11 — полный экран. Данные остаются в `%APPDATA%/oskol-survival/Local Storage`, а не рядом с EXE.

Обе версии полностью офлайн: нет рекламы, аналитики, аккаунтов, сетевой игры, внешних ресурсов при запуске. Android не запрашивает INTERNET. Windows блокирует HTTP/HTTPS-запросы и не включает Node.js в игровом контексте.

## Управление

| Действие | ПК | Телефон |
|---|---|---|
| Движение / обзор | WASD / мышь или перетаскивание | Левый стик / свайп справа |
| Удар / выстрел | ЛКМ после захвата мыши или F | Кнопка инструмента |
| Действие / лут / установка | E | «Действие» |
| Инвентарь / крафт / стройка | I / C / B; ПКМ с планом | «Рюкзак», затем вкладка |
| Карта / метка | M / клик по карте | Иконка карты / тап |
| Перенос / половина стопки | Перетаскивание или два клика / кнопка ½ | Выбрать слот, затем целевой / кнопка ½ |
| Высота фундамента | Q / Z | + / − над поясом |
| Бег / прыжок | Shift / Space | Кнопки бега / прыжка |
| Перезарядка / поворот постройки | R | Повторный тап по выбранной винтовке / ↻ |
| Улучшение | Возьми киянку, наведи на элемент, E | То же через рюкзак и «Действие» |
| Пауза | Escape | Иконка паузы / системная «Назад» |

## Честные границы текущей итерации

- Это **не feature parity с Rust**: нет сетевой игры, серверов, электрических схем, наземного транспорта, рейдовых таймеров, полноценной баллистики, набора оружия Rust, больших подземелий, продвинутой физики или античита.
- РТ — небольшие авторские 3D-композиции с интерактивным лутом, не копии оригинальных РТ Rust. Основные стены, цистерны и оборудование имеют коллизии; часть округлых объектов использует приближённые AABB; нельзя обещать физическое взаимодействие с каждой трубой или лестницей.
- Боты используют простое steering/проверку видимости, не навигационную сетку промышленного движка. На препятствиях могут застревать. Они не строят и не расширяют свои базы самостоятельно; добыча в хранилище упрощённая. По загрузке живые боты возвращаются к домашнему сектору, HP/смерть сохраняются.
- Человеческие движения процедурно анимируют кости готовых моделей; это не mocap. Геометрия строений/рук/РТ частично процедурная; природные и предметные GLB — лицензированные ассеты, не кубические заглушки.
- Заряд срабатывает сразу, ручной крафт мгновенный; плавка теперь по таймеру внутри печи. Нет очереди производства за время закрытого приложения.
- Добытые ресурсы/ящики пока не респаунятся. Смерть возвращает к берегу с сохранением имущества/построек (не Rust-style loot bag).
- Один активный мир + предыдущая резервная копия, нет облачной синхронизации, экспорта/импорта и нескольких слотов. Совместимость будущих схем сохранений не гарантирована: перед изменением схемы потребуется миграция.
- Графический пресет меняет тени/разрешение/траву сразу; плотность сетки ландшафта и исходные LOD деревьев выбираются при загрузке острова (для полного переключения нужен перезапуск).
- Большие острова дольше создаются; деревья и трава ограничены дальностью пресета, без маскировки туманом возможно появление растительности на границе дальности. Река проходима вброд, полноценного плавания и мостовой системы ещё нет. На телефоне начни с 4 км и низкой/средней графики, а не с 8 км.
- FPS/нагрев/расход батареи не профилировались на физическом телефоне. Эмулятор и браузерные проверки не заменяют твой тест.

## Разработка и проверка

```sh
npm ci --ignore-scripts
npm run dev           # собирает JS, сервер 0.0.0.0:3000
npm test              # правила, сохранения, лицензии/GLB
npm run test:survival # при запущенном сервере: настоящая браузерная игра
npm run test:browser  # регрессия сохранённой аркады /layer/
```

Для Windows `npm ci` (без `--ignore-scripts`, чтобы скачать Electron), затем `npm run desktop` или `npm run build:windows`. Android: JDK17, Gradle8.13, SDK35, `cd android && gradle :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`.

Локально: **64 unit-теста**, полный браузерный сценарий и отдельная регрессия прежней аркады. Браузер проверяет 36 слотов, собственное хранилище/сохранение, внутреннюю плавку, стройку планом/три улучшения, один огнестрел при ×50/удаление пустого лута, коноплю ×2, болтовую винтовку/смерть бота, возврат захвата мыши, сухой лагерь 4-км карты, карту/метку, биомы, палубу/лут нефтеплатформы, лодку/выход, touch UI, high-качество, видимость мира за руками и отсутствие внешних запросов/ошибок JS/шейдеров. CI запускает те же проверки; отдельно проверяет Android WebView в эмуляторе и desktop Electron перед упаковкой. Готовые бинарники хранятся в Actions artifacts, не в Git. Исходные `.exe/.dll/.rar` из корня репозитория к игре не относятся, не запускались и не входят ни в APK, ни в Windows-сборку.

Лицензии и точные источники: `web/assets/credits.html`, `web/assets/manifest.json`, `web/assets/licenses/`. Скрипты `scripts/fetch-assets.py` и `scripts/convert-tree.py` воспроизводят получение/конвертацию ассетов. Водяной знак обнаруженной неподходящей текстуры не удалялся: сама текстура исключена из проекта.

### Что прислать после теста

Платформа/модель устройства, версия WebView или Windows/GPU, графический пресет, размер/зерно/множитель, что нажал, что ожидал и что произошло. Особенно важны: первые 10 минут, чувство движения/удара, читаемость HUD, прицел/добыча, установка и улучшение, поведение ботов, загрузка сохранения и нагрев. Следующие изменения делать отдельными DEV-итерациями, не называть эту сборку финальной.
