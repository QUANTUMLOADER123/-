ОСКОЛ — DEV 0.5, тестовая итерация 02
Windows 10/11 x64. Запустите Oskol.exe / портативный EXE. F11 — полный экран.
Игра полностью офлайн. Сохранения: %APPDATA%/oskol-survival/Local Storage.
WASD — движение, мышь/перетаскивание — обзор, F/ЛКМ — удар/выстрел, E — действие.
I — рюкзак, C — крафт, B — стройка, M — карта, R — перезарядка/поворот, 1—6 — быстрый выбор.
При первом запуске выберите размер, добычу, сложность и зерно. Есть автоматическое сохранение и «Сохранить сейчас» на паузе.
Это НЕ Rust, не финальная версия и не продукт Facepunch. Боты упрощены: патруль, добыча, возвращение, защита базы.
Сборка не подписана сертификатом Windows. Не отключайте системную защиту; при сомнениях соберите из исходников.
