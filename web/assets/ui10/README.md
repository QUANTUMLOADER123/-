# ОСКОЛ DEV10 — интерфейс, ресурсы и референсы

## Оформление

`island-keyart.jpg` — оригинальная AI-иллюстрация, созданная для этого проекта 2026-11-04. Это **концепт-арт, не скриншот игрового процесса**; так же подписан в меню и загрузке. Не содержит логотипов/ассетов Facepunch. Один и тот же локальный JPEG используется фоном загрузки и карточки обновления; сетевых запросов к генератору/референсам из игры нет. SHA-256 записан в `../manifest.json`.

Сюжет: извилистая дорога с развилкой, сосны и травянистые обочины, небольшая промышленная радиобашня на берегу северного острова. Безымянный выживший в простой оливковой куртке со спины, прохладный свет, приглушённые зелёные/серые/ржавые цвета. Все надписи и элементы управления — отдельные HTML/CSS, не нарисованные неработающие кнопки внутри изображения.
