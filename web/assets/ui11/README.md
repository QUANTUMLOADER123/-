# ОСКОЛ DEV11 — иллюстрации загрузки

Восемь отдельных оригинальных AI-иллюстраций созданы 2026-11-04 специально для игры. **Это концепт-арт, не скриншоты игрового процесса и не обещание такого качества 3D-графики.** На экране есть соответствующая подпись. Нет извлечённых изображений, логотипов, персонажей или моделей Rust / Facepunch. Все элементы интерфейса — настоящий HTML/CSS поверх фона.

Первый фон при входе — ночной дозор по описанию пользователя. Остальные перемешиваются; меняются приблизительно каждые 10 секунд либо по кнопке «Следующий фон». Изображения лежат локально, никаких сетевых галерей/телеметрии. Следующая картинка декодируется перед плавным переходом; при ошибке остаётся прежняя. В меню эта галерея не запускается. После отмены/входа таймер остановлен, позднее завершение декодирования не меняет фон следующего входа.

Промпты: самостоятельные широкоформатные реалистично-живописные сцены северного острова, без надписей/брендов/интерфейса, с тёмной нижней областью под загрузочную панель. У ночного сюжета — два анонимных персонажа в самодельной броне, зелёные окуляры ПНВ и лазерные лучи, без стрельбы/ранений; остальные сюжеты — отдельные окружения ниже.
